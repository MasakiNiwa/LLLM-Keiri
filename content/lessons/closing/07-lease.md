## 2 つのリース取引（これまでの基準）

| 種類                         | 内容                                                       | 処理                   |
| ---------------------------- | ---------------------------------------------------------- | ---------------------- |
| ファイナンス・リース取引     | 途中で解約できず、使う利益とコストのほとんどが借り手にある | 売買と同じように処理   |
| オペレーティング・リース取引 | ファイナンス・リース以外                                   | 賃貸借と同じように処理 |

## ファイナンス・リース（利子抜き法）

リース料の合計に含まれる利息を除いた額（見積現金購入価額など）で、**リース資産** と **リース債務** を計上します。

```shiwake
# 期首に、備品をファイナンス・リースで借りた（見積現金購入価額 500,000 円、リース料は年 110,000 円 × 5 年）
リース資産 500,000 / リース債務 500,000

# 期末に、リース料 110,000 円を支払った（利息 10,000 円は、学習用に毎年同じ額とする）
リース債務 100,000 / 普通預金 110,000
支払利息 10,000 /

# 決算で、リース資産を耐用年数（リース期間 5 年）で減価償却した
減価償却費 100,000 / 減価償却累計額 100,000
```

> [!NOTE]
> 利息を含めたリース料の合計で資産・負債を計上する **利子込み法** もあります（重要性が乏しい場合など）。

## オペレーティング・リース

```shiwake
# コピー機のリース料 30,000 円を普通預金から支払った（オペレーティング・リース）
支払リース料 30,000 / 普通預金 30,000
```

## 新しいリース会計基準

2024 年に公表された「リースに関する会計基準」（企業会計基準第 34 号）では、借り手は原則として **すべてのリース** について資産（使用権資産）と負債（リース負債）を計上します。
2027 年 4 月 1 日以後に始まる事業年度の期首から適用されます（早く適用することもできます）。

> [!WARNING]
> 新しい基準には、短期のリースや少額のリースの簡便な扱い、リース期間の決め方などの細かい決まりがあります。適用する会社は基準と適用指針で確かめてください。中小企業は、中小企業の会計に関する指針などによることもできます。

```quiz
type: shiwake
question: ファイナンス・リース取引で、機械を借りた。見積現金購入価額は 800,000 円で、利子抜き法による。
answer: リース資産 800,000 / リース債務 800,000
explanation: 利子抜き法では、利息を含まない額で資産と負債を計上します。
```
