## 経過勘定とは

家賃・保険料・利息のように、**一定期間ずっと続くサービス** の代金は、払った（受け取った）時期と、サービスの期間がずれることがあります。
決算で当期の分だけを費用・収益にするため、ずれた分を一時的に記録する科目が **経過勘定** です。

|      | 先に払った・受け取った | まだ払っていない・受け取っていない |
| ---- | ---------------------- | ---------------------------------- |
| 費用 | **前払費用**（資産）   | **未払費用**（負債）               |
| 収益 | **前受収益**（負債）   | **未収収益**（資産）               |

## 前払費用（費用の前払い）

決算日 3 月 31 日。12 月 1 日に 1 年分の保険料 120,000 円を支払っていた。
4〜11 月の 8 か月分は来期の費用なので、決算で費用から除きます。

```shiwake
# 支払ったとき（12/1）
保険料 120,000 / 普通預金 120,000

# 決算（3/31）: 8 か月分 80,000 円を前払費用に
前払費用 80,000 / 保険料 80,000
```

## 未払費用（費用の未払い）

決算日 3 月 31 日。借入金の利息は 6 月末に半年分を後払いする。1〜3 月の 3 か月分 6,000 円は当期の費用です。

```shiwake
# 決算（3/31）: 当期分の利息を未払費用に
支払利息 6,000 / 未払費用 6,000
```

## 前受収益（収益の前受け）

決算日 3 月 31 日。2 月 1 日に、貸している部屋の家賃 6 か月分 60,000 円を受け取っていた。4〜7 月の 4 か月分は来期の収益です。

```shiwake
# 決算（3/31）: 4 か月分 40,000 円を前受収益に
受取家賃 40,000 / 前受収益 40,000
```

## 未収収益（収益の未収）

決算日 3 月 31 日。貸付金の利息は 9 月末にまとめて受け取る。10〜3 月の 6 か月分 9,000 円は当期の収益です。

```shiwake
# 決算（3/31）: 当期分の利息を未収収益に
未収収益 9,000 / 受取利息 9,000
```

## 翌期首の再振替仕訳

経過勘定は、翌期の最初の日に **逆の仕訳**（再振替仕訳）をして、元の費用・収益の勘定に戻します。
こうすると、翌期に実際に支払ったり受け取ったりしたときに、ふつうに仕訳するだけで正しい金額になります。

```shiwake
# 翌期首（4/1）: 前払費用を保険料に戻す
保険料 80,000 / 前払費用 80,000
```

> [!TIP]
> 見分け方は「お金が先か、サービスが先か」。お金が先なら **前**払・**前**受、サービスが先なら **未**払・**未**収です。

```quiz
type: shiwake
question: 決算日 3 月 31 日。1 月 1 日に 1 年分の家賃 240,000 円を支払い、支払家賃で処理している。来期分を繰り延べる。
answer: 前払費用 180,000 / 支払家賃 180,000
hint: 4〜12 月の 9 か月分が来期の分です。
explanation: 240,000 × 9/12 ＝ 180,000 円。来期分を費用から除き、前払費用（資産）にします。
```

```quiz
type: choice
question: 当期分の利息をまだ受け取っていないとき、決算で使う科目は？
choices:
  - 前受収益
  - 未収収益
  - 未払費用
answer: 1
explanation: サービス（お金を貸している）が先で、お金をまだ受け取っていない収益なので、未収収益（資産）です。
```
