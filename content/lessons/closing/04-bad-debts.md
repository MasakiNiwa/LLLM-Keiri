## 貸倒れと貸倒引当金

取引先の倒産などで、売掛金や受取手形が回収できなくなることを **貸倒れ** といいます。
過去の経験などから、期末の売掛金のうち将来貸し倒れそうな額を見積もり、決算で **貸倒引当金** を設定します。

> [!POINT]
> 貸倒れの原因は当期の売上にあるので、当期の費用（貸倒引当金繰入）として計上します。
> 貸倒引当金は売掛金などのマイナス（評価勘定）で、貸方で増えます。

## 差額補充法

見積額と、いま残っている貸倒引当金の残高との **差額だけ** を繰り入れます。

| 売掛金の期末残高 | 貸倒実績率 | 見積額 | 引当金の残高 | 繰り入れる額 |
| ---------------: | ---------: | -----: | -----------: | -----------: |
|          500,000 |         2% | 10,000 |        4,000 |        6,000 |

```shiwake
# 決算: 見積額 10,000 円、残高 4,000 円 → 差額 6,000 円を繰り入れ
貸倒引当金繰入 6,000 / 貸倒引当金 6,000
```

残高のほうが多いときは、多い分を取り崩して収益にします。

```shiwake
# 決算: 見積額 10,000 円、残高 13,000 円 → 3,000 円を戻し入れ
貸倒引当金 3,000 / 貸倒引当金戻入 3,000
```

## 実際に貸し倒れたとき

**前期以前** の売掛金が貸し倒れたら、まず貸倒引当金を取り崩し、足りない分は貸倒損失にします。

```shiwake
# 前期の売掛金 8,000 円が貸し倒れた（貸倒引当金の残高 10,000 円）
貸倒引当金 8,000 / 売掛金 8,000

# 前期の売掛金 15,000 円が貸し倒れた（貸倒引当金の残高 10,000 円）
貸倒引当金 10,000 / 売掛金 15,000
貸倒損失 5,000 /
```

**当期に発生した** 売掛金が貸し倒れたときは、貸倒引当金（前期末に設定したもの）は使わず、全額を貸倒損失にします。

```shiwake
# 当期に販売した分の売掛金 6,000 円が貸し倒れた
貸倒損失 6,000 / 売掛金 6,000
```

> [!NOTE]
> 前期以前に貸倒れとして処理した債権を当期に回収できたときは、**償却債権取立益**（収益）にします。
> 法人税では、貸倒引当金を損金にできる法人が中小法人などに限られています（実務では税務上の扱いも確認します）。

```quiz
type: shiwake
question: 決算にあたり、売掛金の期末残高 800,000 円に対して 3% の貸倒引当金を差額補充法で設定する。貸倒引当金の残高は 9,000 円である。
answer: 貸倒引当金繰入 15,000 / 貸倒引当金 15,000
hint: 見積額 800,000 × 3% から、いまの残高を引きます。
explanation: 見積額は 24,000 円。残高 9,000 円との差額 15,000 円を繰り入れます。
```
