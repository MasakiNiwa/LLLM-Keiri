## 本店と支店の帳簿

支店が多い会社では、支店でも帳簿をつけ（支店独立会計制度）、決算で本店と支店の帳簿を合わせて会社全体の財務諸表を作ります。

本店と支店の間のやりとりは、会社の外との取引ではないので、次の勘定で記録します。

| 帳簿       | 相手を表す勘定 |
| ---------- | -------------- |
| 本店の帳簿 | **支店**       |
| 支店の帳簿 | **本店**       |

本店の「支店」と、支店の「本店」は、貸借が逆で **同じ金額** になります。

## 仕訳の例

```shiwake
# 【本店】支店へ現金 100,000 円を送った
支店 100,000 / 現金 100,000

# 【支店】本店から現金 100,000 円を受け取った
現金 100,000 / 本店 100,000
```

```shiwake
# 【本店】支店の買掛金 50,000 円を、本店が普通預金から代わりに支払った
支店 50,000 / 普通預金 50,000

# 【支店】本店が買掛金を支払ってくれた
買掛金 50,000 / 本店 50,000
```

## 会社全体の財務諸表

本店と支店の帳簿を合わせるとき、「支店」と「本店」は相殺して消します（会社の中の貸し借りなので）。

> [!POINT]
> 連結決算でグループ内の取引を消すのと同じ考え方です。本支店会計は 1 つの会社の中、連結は会社のグループです。

```quiz
type: shiwake
question: 【支店】本店から商品 80,000 円（原価）を受け取った（仕入で記録する）。
answer: 仕入 80,000 / 本店 80,000
explanation: 支店では、本店からの受け入れを「本店」の勘定で記録します。本店の帳簿では「支店 80,000 / 仕入 80,000」などと記録します。
```
