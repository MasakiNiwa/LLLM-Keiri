## 連結で見るときの注意

連結財務諸表には、子会社の外部の株主（非支配株主）の分も含まれます。比率を出すときは、何を分子・分母にするかに気をつけます。

| 項目       | 連結での扱い                                                     |
| ---------- | ---------------------------------------------------------------- |
| 当期純利益 | ROE などには **親会社株主に帰属する当期純利益** を使うことが多い |
| 自己資本   | 純資産から **非支配株主持分** などを除いた額                     |
| 総資産     | グループ内の債権債務・投資と資本を消去したあとの額               |

> [!POINT]
> 連結の ROE ＝ 親会社株主に帰属する当期純利益 ÷（純資産 − 非支配株主持分）。親会社の株主から見た利益率です。

## セグメント情報で中身を見る

連結の数字は、いくつもの事業や地域の合計です。セグメント情報を見ると、次のようなことがわかります。

- どのセグメントが売上・利益の多くを稼いでいるか
- 利益率の高いセグメントと低いセグメント
- セグメント資産に対して、どれだけ利益を上げているか（セグメントの ROA のような見方）
- 調整額が大きいとき、グループ内の取引がどれだけあるか

## アプリで確かめる

「連結」ページで、事例ごとに次のタブを見比べてみましょう。

1. **連結財務諸表** — グループ全体の数字
2. **分析** — 比率（親会社株主の分で計算）
3. **セグメント**（セグメントのある事例）— 事業・地域ごとの数字と調整額

修正仕訳の「反映」を外すと、連結の数字と比率がどう変わるかも確かめられます（たとえば、未実現利益を消去しないと利益が大きく見える）。

```quiz
type: choice
question: 連結の ROE を計算するとき、ふつう分母に使うのは？
choices:
  - 純資産の合計（非支配株主持分を含む）
  - 純資産から非支配株主持分を除いた額
  - 総資産
answer: 1
explanation: 親会社株主から見た利益率なので、分子は親会社株主に帰属する当期純利益、分母は非支配株主持分を除いた自己資本を使います。
```
