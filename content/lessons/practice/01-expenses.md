## 経費精算とは

従業員が会社の仕事で使ったお金（交通費・文房具・接待の飲食代など）を、会社が払い戻すことを **経費精算** といいます。
経理は、領収書（レシート）と申請の内容を確かめて、どの費用の科目にするかを決め、仕訳を入れます。

| 使いみち                   | 科目の例   |
| -------------------------- | ---------- |
| 電車・タクシー・出張の宿泊 | 旅費交通費 |
| 文房具・コピー用紙         | 消耗品費   |
| 取引先との会食・お土産     | 接待交際費 |
| 社内の打合せの飲み物・弁当 | 会議費     |
| 切手・電話・インターネット | 通信費     |

## 従業員が立て替えたとき

従業員が自分のお金で払い、あとで精算するときは、会社の **費用** と、従業員に払う **債務**（未払金）を記録します。

```shiwake
# 営業担当者が取引先へのタクシー代 3,200 円を立て替えた（月末にまとめて振り込む）
旅費交通費 3,200 / 未払金 3,200

# 月末に、立替分を普通預金から振り込んだ
未払金 3,200 / 普通預金 3,200
```

> [!TIP]
> その場で現金で払い戻すなら「旅費交通費 3,200 / 現金 3,200」の 1 本で済みます。

## 仮払金（出張の前に渡す）

出張の前に、おおよその金額を先に渡しておくことがあります。使いみちと金額がまだ決まらないので、**仮払金**（資産）にしておき、出張から戻って精算したときに費用に振り替えます。

```shiwake
# 出張の前に、旅費の概算 50,000 円を現金で渡した
仮払金 50,000 / 現金 50,000

# 出張から戻り、旅費交通費 46,000 円の精算を受け、残りの現金 4,000 円を受け取った
旅費交通費 46,000 / 仮払金 50,000
現金 4,000 /
```

> [!WARNING]
> 仮払金は「一時的な置き場所」です。精算が済んだら必ず残高を 0 に戻します。月末・決算で残っていたら、精算を忘れていないか確かめます。

## 会社が従業員のために立て替えたとき

逆に、会社が従業員の個人的な支払いを立て替えたときは **立替金**（資産）にします（給料から差し引くなど）。

```shiwake
# 従業員の個人的な買い物 5,000 円を、会社の現金で立て替えた
立替金 5,000 / 現金 5,000
```

> [!POINT]
> 経費精算では、(1) 会社の仕事に使ったか、(2) 使いみちに合う科目か、(3) 領収書などの証拠があるか、を確かめます。
> 消費税の仕入税額控除には、インボイス（適格請求書）の保存などの要件があります（税金の分野で学びます）。

```quiz
type: shiwake
question: 出張の前に旅費の概算 30,000 円を普通預金から振り込んでいたが、出張から戻り、旅費交通費 32,000 円の精算を受けた。不足の 2,000 円は現金で支払った。
answer: |
  旅費交通費 32,000 / 仮払金 30,000
  / 現金 2,000
hint: 仮払金をすべて費用に振り替え、足りない分を払います。
explanation: 仮払金 30,000 円を取り崩し、実際の旅費 32,000 円を旅費交通費にします。足りない 2,000 円は現金で支払います。
```

```quiz
type: choice
question: 取引先との会食代を従業員が立て替え、月末に振り込むことにした。費用の科目と、相手の科目の組み合わせは？
choices:
  - 会議費 と 立替金
  - 接待交際費 と 未払金
  - 接待交際費 と 仮払金
answer: 1
explanation: 取引先との飲食は接待交際費。従業員に後で払う義務は未払金です。
```
