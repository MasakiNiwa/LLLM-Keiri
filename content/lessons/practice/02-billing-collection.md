## 請求から入金まで

掛けで売った代金は、次の流れで回収します。

1. 商品を渡す・サービスを提供する → **売上と売掛金を記録**
2. 締め日（例: 月末）に **請求書** を出す
3. 支払期日に、得意先から振り込まれる
4. 入金がどの請求書の分かを突き合わせて、**売掛金を消す（入金消込）**

```shiwake
# 4 月中に A 社へ商品を掛けで販売した（合計）
売掛金 300,000 / 売上 300,000

# 5 月末に、A 社から 4 月分の代金が普通預金に振り込まれた
普通預金 300,000 / 売掛金 300,000
```

## 入金消込のポイント

> [!POINT]
> 消込は「得意先ごと・請求書ごと」に行います。売掛金の合計が合っていても、どの得意先の、どの請求が残っているかがわからないと、催促も貸倒れの判断もできません。

入金の金額が請求額と合わないときは、理由を確かめてから仕訳します。

| よくある理由                       | 対応                                         |
| ---------------------------------- | -------------------------------------------- |
| 振込手数料を差し引いて振り込まれた | 取り決めにより、当社負担なら支払手数料にする |
| 複数の請求をまとめて振り込まれた   | 請求書ごとに分けて消し込む                   |
| 一部だけ入金された                 | 残りは売掛金のまま。得意先に確認する         |
| 入金が多い（二重払いなど）         | 得意先に確認し、返金するまで預り金などにする |

```shiwake
# 売掛金 110,000 円の入金があったが、振込手数料 440 円が差し引かれていた（手数料は当社負担の取り決め）
普通預金 109,560 / 売掛金 110,000
支払手数料 440 /
```

> [!WARNING]
> 手数料を得意先が負担する取り決めなのに差し引かれていたときは、費用にせず、売掛金を残して得意先に確認します。

## 先に代金を受け取るとき

商品を渡す前に代金を受け取ったときは、売上ではなく **前受金**（負債）にします。

```shiwake
# 注文を受け、代金 50,000 円が先に振り込まれた
普通預金 50,000 / 前受金 50,000

# 商品を渡した
前受金 50,000 / 売上 50,000
```

```quiz
type: shiwake
question: B 社への売掛金 220,000 円について、振込手数料 660 円を差し引いた額が普通預金に入金された。手数料は当社が負担する取り決めである。
answer: |
  普通預金 219,340 / 売掛金 220,000
  支払手数料 660 /
explanation: 売掛金は請求額の 220,000 円をすべて消し、差し引かれた手数料 660 円は支払手数料にします。
```

```quiz
type: choice
question: 得意先から、請求額 100,000 円のうち 60,000 円だけ入金された。正しい対応は？
choices:
  - 売掛金 100,000 円を消し、差額は雑損にする
  - 入金した 60,000 円だけ売掛金を消し、残りは得意先に確認する
  - 入金額に合わせて売上を 60,000 円に直す
answer: 1
explanation: 入金した分だけ消し込み、残りは売掛金のまま。理由（支払い漏れ・値引きの依頼など）を得意先に確認します。
```
