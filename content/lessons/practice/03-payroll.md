## 給料から差し引くもの

会社は、給料を払うときに次のものを差し引き（天引き）、従業員に代わって国・自治体・保険者に納めます。

| 差し引くもの                         | 科目             | 納める先・時期（原則）                           |
| ------------------------------------ | ---------------- | ------------------------------------------------ |
| 源泉所得税                           | 所得税預り金     | 税務署。給料を払った月の翌月 10 日まで           |
| 住民税（特別徴収）                   | 預り金           | 市区町村。翌月 10 日まで                         |
| 社会保険料（健康保険・厚生年金など） | 社会保険料預り金 | 年金事務所など。翌月末までに会社の負担分と一緒に |

> [!NOTE]
> 源泉所得税は、給与の支払いを受ける人が常時 10 人未満の会社なら、届け出により半年ごとにまとめて納める特例（納期の特例）もあります。

預かったお金は会社のものではないので、納めるまで **負債（預り金）** にしておきます。

## 給料日の仕訳

```shiwake
# 4 月分の給料 300,000 円から、源泉所得税 7,000 円・住民税 12,000 円・社会保険料 45,000 円を差し引き、残りを普通預金から振り込んだ
給料 300,000 / 所得税預り金 7,000
/ 預り金 12,000
/ 社会保険料預り金 45,000
/ 普通預金 236,000
```

> [!POINT]
> 費用になる「給料」は差し引く前の総額（300,000 円）です。振り込む手取り額ではありません。

## 納付の仕訳

```shiwake
# 5 月 10 日、源泉所得税と住民税を納めた
所得税預り金 7,000 / 普通預金 19,000
預り金 12,000 /

# 5 月末、社会保険料を納めた（従業員の負担分 45,000 円と、会社の負担分 45,000 円）
社会保険料預り金 45,000 / 普通預金 90,000
法定福利費 45,000 /
```

```widget
type: payroll
```

健康保険料と厚生年金保険料は、会社と従業員がおおむね半分ずつ負担します（労使折半）。会社の負担分は **法定福利費**（費用）です。

> [!NOTE]
> 実際の保険料は、標準報酬月額と保険料率（健康保険は加入している健康保険組合や都道府県によって違う）で決まります。ここでは計算は省き、金額は与えられたものとしています。
> 雇用保険料は会社と従業員の負担割合が違うなど、細かい決まりがあります。

## 月次決算での会社負担分

社会保険料は翌月に納めるので、月次で費用を正しく出すには、当月分の会社の負担分を **未払費用** として計上しておく方法もあります。

```shiwake
# 4 月末、4 月分の会社負担の社会保険料 45,000 円を見越し計上した
法定福利費 45,000 / 未払費用 45,000
```

（この場合、5 月末の納付では「社会保険料預り金 45,000・未払費用 45,000 / 普通預金 90,000」となります。）

```quiz
type: shiwake
question: 給料 250,000 円から、源泉所得税 5,000 円と社会保険料 37,000 円を差し引き、残りを普通預金から振り込んだ。
answer: |
  給料 250,000 / 所得税預り金 5,000
  / 社会保険料預り金 37,000
  / 普通預金 208,000
explanation: 給料は総額で費用にします。差し引いた分は納めるまで預り金（負債）。手取り 208,000 円を振り込みます。
```

```quiz
type: choice
question: 会社が負担する社会保険料は、どの科目にする？
choices:
  - 給料
  - 社会保険料預り金
  - 法定福利費
answer: 2
explanation: 会社負担分は会社の費用で、法定福利費にします。社会保険料預り金は従業員から預かった分です。
```
