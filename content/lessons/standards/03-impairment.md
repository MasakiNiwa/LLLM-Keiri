## 減損とは

固定資産は、使い続けることで投資した額を回収する前提で、取得原価から減価償却していきます。
ところが、店舗の売上が大きく落ちた、土地の値段が大きく下がった、などで回収の見込みがなくなったときは、帳簿価額を回収できる額まで減らします。これが **減損処理** です。

## 3 つの段階

1. **兆候** — 営業損益が続けてマイナス、使い方の大きな変更、経営環境の著しい悪化、市場価格の著しい下落など
2. **認識の判定** — 兆候があれば、**割引前の将来キャッシュ・フロー** の合計と帳簿価額を比べる。下回れば減損損失を認識する
3. **測定** — 帳簿価額を **回収可能価額** まで減らす。回収可能価額は、**正味売却価額**（売ったらいくらか）と **使用価値**（使い続けたら生むキャッシュ・フローの現在価値）の高いほう

> [!POINT]
> 判定は「割引前」、測定は「回収可能価額（現在価値などを使う）」。判定で割引前を使うのは、減損が本当に必要なときだけ処理するためです。

```shiwake
# 建物（帳簿価額 5,000,000 円）の回収可能価額が 3,000,000 円になったので、減損損失を計上した
減損損失 2,000,000 / 建物 2,000,000
```

```widget
type: impairment
```

> [!NOTE]
> 実務では、キャッシュ・フローを生む最小の単位（**資産グループ**。店舗ごとなど）で判定します。日本の基準では、一度計上した減損損失を戻し入れません。

```quiz
type: choice
question: 帳簿価額 800 万円、割引前将来キャッシュ・フロー 900 万円、回収可能価額 600 万円の資産。減損損失は？
choices:
  - 0 円（認識しない）
  - 200 万円
  - 300 万円
answer: 0
explanation: 割引前将来キャッシュ・フロー（900 万円）が帳簿価額（800 万円）以上なので、減損損失は認識しません。
```

```quiz
type: choice
question: 正味売却価額 250 万円、使用価値 280 万円のとき、回収可能価額は？
choices:
  - 250 万円
  - 265 万円
  - 280 万円
answer: 2
explanation: 回収可能価額は、正味売却価額と使用価値の高いほうです。
```
