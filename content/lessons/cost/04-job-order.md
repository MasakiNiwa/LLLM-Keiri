## 個別原価計算とは

注文住宅・船・特注の機械のように、注文ごとに仕様が違う製品を作るときは、注文ごとに **製造指図書** を発行し、指図書ごとに原価を集めます。これが **個別原価計算** です。

## 原価計算表

|            | No.101     | No.102     | No.103  | 合計    |
| ---------- | ---------- | ---------- | ------- | ------- |
| 直接材料費 | 120,000    | 90,000     | 40,000  | 250,000 |
| 直接労務費 | 180,000    | 150,000    | 70,000  | 400,000 |
| 製造間接費 | 60,000     | 50,000     | 40,000  | 150,000 |
| 合計       | 360,000    | 290,000    | 150,000 | 800,000 |
| 状態       | 完成・引渡 | 完成・在庫 | 未完成  |         |

- 完成した指図書（No.101・No.102）の原価 → **製品**
- 未完成（No.103）→ 月末の **仕掛品** のまま
- 引き渡した（No.101）→ **売上原価**

```shiwake
# No.101 と No.102 が完成した
製品 650,000 / 仕掛品 650,000

# No.101 を顧客に引き渡した
売上原価 360,000 / 製品 360,000
```

> [!TIP]
> 製造間接費は、指図書ごとの直接作業時間などで配賦します（[製造間接費の配賦と差異分析](#/learn/cost-overhead)）。

```quiz
type: shiwake
question: 上の表で、No.103 も完成した。
answer: 製品 150,000 / 仕掛品 150,000
explanation: 完成した指図書の原価を、仕掛品から製品に振り替えます。
```
