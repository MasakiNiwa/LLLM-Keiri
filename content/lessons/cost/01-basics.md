## 工業簿記とは

商品を仕入れて売る商業簿記と違い、製造業では材料を加工して製品を作ります。
**工業簿記** は、製品を作るのにかかった **原価** を計算し、帳簿に記録するしくみです。原価がわかると、売値の決定や、むだの発見に使えます。

## 原価の分け方

| 形態で分ける | 内容                                     |
| ------------ | ---------------------------------------- |
| **材料費**   | 素材・部品・工場の消耗品など             |
| **労務費**   | 工場で働く人の賃金・給料・賞与など       |
| **経費**     | 外注加工賃・工場の減価償却費・電気代など |

| 製品との関係で分ける | 内容                                                         |
| -------------------- | ------------------------------------------------------------ |
| **直接費**           | どの製品にかかったか、はっきりわかる（製品 A の部品など）    |
| **間接費**           | 複数の製品に共通でかかる（工場の電気代など）→ **製造間接費** |

## 勘定の流れ

```shiwake
# 材料 300,000 円を掛けで買った
材料 300,000 / 買掛金 300,000

# 材料を消費した（直接材料費 250,000 円、間接材料費 30,000 円）
仕掛品 250,000 / 材料 280,000
製造間接費 30,000 /

# 賃金を消費した（直接労務費 400,000 円、間接労務費 100,000 円）
仕掛品 400,000 / 賃金 500,000
製造間接費 100,000 /

# 工場の電気代 20,000 円を普通預金から支払った（間接経費）
製造間接費 20,000 / 普通預金 20,000

# 製造間接費（30,000 ＋ 100,000 ＋ 20,000）を、製品に配賦した
仕掛品 150,000 / 製造間接費 150,000

# 製品が完成した
製品 800,000 / 仕掛品 800,000

# 製品（原価 600,000 円）を 900,000 円で掛けで売った
売掛金 900,000 / 売上 900,000
売上原価 600,000 / 製品 600,000
```

> [!POINT]
> 原価は **材料・賃金・経費 → 仕掛品（と製造間接費）→ 製品 → 売上原価** と流れます。直接費は仕掛品へ直接、間接費は製造間接費に集めてから配賦します。

> [!NOTE]
> 原価計算の考え方の基本は「原価計算基準」（1962 年）にまとめられています。古い基準ですが、今も実務と検定試験のよりどころです。

```quiz
type: choice
question: 工場の電気代（複数の製品に共通）は、どの勘定に集める？
choices:
  - 仕掛品
  - 製造間接費
  - 製品
answer: 1
explanation: 複数の製品に共通の原価は、いったん製造間接費に集め、基準を決めて仕掛品に配賦します。
```

```quiz
type: shiwake
question: 材料を消費した。直接材料費は 180,000 円、間接材料費は 20,000 円である。
answer: |
  仕掛品 180,000 / 材料 200,000
  製造間接費 20,000 /
explanation: 直接材料費は仕掛品へ、間接材料費は製造間接費へ振り替えます。
```
