## 2 つの会計監査

| 項目         | 金融商品取引法の監査                                   | 会社法の監査                                                                   |
| ------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| 対象         | 上場会社など（有価証券報告書を出す会社）               | 会計監査人を置く会社（大会社〈資本金 5 億円以上または負債 200 億円以上〉など） |
| 監査する書類 | 有価証券報告書の財務諸表（連結・個別）、内部統制報告書 | 計算書類（貸借対照表・損益計算書など）とその附属明細書、連結計算書類           |
| 目的         | 投資家の保護                                           | 株主・債権者の保護                                                             |

上場会社では、両方の監査を同じ監査法人（または公認会計士）が行うのがふつうです。

## 経営者と監査人の責任の分担

- **財務諸表を作る責任は経営者（会社）** にあります。経理が作る数字そのものです。
- **監査人の責任は、財務諸表が適正かどうかについて意見を述べること** です。

監査人が数字を作るわけではありません。「監査で見てもらえるから大丈夫」ではなく、会社が正しい財務諸表を作り、根拠を示す必要があります（**二重責任の原則**）。

## 合理的な保証と重要性

監査は、すべての取引を確かめるのではなく、リスクの高いところに手続を集中して、**重要な虚偽表示が無いことについて合理的な保証**（絶対的ではないが高い水準の保証）を得るものです。

**重要性**: 利用者の判断を変えるほどの誤りかどうかの基準です。監査人は、たとえば税引前利益の一定割合などを目安に金額の基準を決めます（具体的な割合は監査人の判断）。金額が小さくても、不正や法令違反など性質が重要なものは重要と判断されます。

## 監査意見の種類

| 意見           | 意味                                     |
| -------------- | ---------------------------------------- |
| 無限定適正意見 | すべての重要な点で適正                   |
| 限定付適正意見 | 一部に問題があるが、それを除けば適正     |
| 不適正意見     | 財務諸表全体として適正でない             |
| 意見不表明     | 十分な証拠が得られず、意見を述べられない |

無限定適正意見以外は、株価・取引所の対応・資金調達に大きな影響があります。経理の仕事は、無限定適正意見を **当たり前に** 得られる決算を作ることです。

## 監査上の主要な検討事項（KAM）

上場会社などの監査報告書には、監査人が特に重要と判断した事項（**KAM**）とその対応が書かれます。収益認識・のれんや固定資産の減損・繰延税金資産の回収可能性などがよく取り上げられます。自社の KAM は、監査人が何を重く見ているかを知る手がかりです。
