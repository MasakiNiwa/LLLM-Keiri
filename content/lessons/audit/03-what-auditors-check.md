## 5 つの観点（アサーション）

| 観点           | 確かめたいこと                       | 例                                   |
| -------------- | ------------------------------------ | ------------------------------------ |
| 実在性・発生   | 本当にあるか・本当に起きたか         | 架空の売上・売掛金が無いか           |
| 網羅性         | 漏れなく計上しているか               | 未払の費用・負債の計上漏れが無いか   |
| 権利と義務     | 会社のものか・会社の義務か           | 預かり在庫を自社の在庫にしていないか |
| 評価と期間配分 | 金額が正しいか・正しい期に計上したか | 貸倒引当金・評価減・売上の期ズレ     |
| 表示と開示     | 正しく分類・注記しているか           | 流動・固定の区分、注記の漏れ         |

資産・収益は **過大**（実在性）、負債・費用は **過少**（網羅性）がリスクになりやすいので、監査人の見る向きもそれに合わせて変わります。

## 主な監査手続

| 手続         | 内容                                               | 主な対象                     |
| ------------ | -------------------------------------------------- | ---------------------------- |
| 実査         | 現物を数える                                       | 現金・有価証券・手形         |
| 立会         | 会社の棚卸に立ち会い、数え方を観察し、一部を数える | 棚卸資産                     |
| 確認         | 取引先・銀行に直接、残高を問い合わせる             | 預金・売掛金・買掛金・借入金 |
| 証憑の確かめ | 契約書・請求書・出荷記録などと帳簿を突き合わせる   | 売上・仕入・固定資産         |
| 再計算       | 会社の計算をやり直す                               | 減価償却・引当金・税金       |
| 分析的手続   | 前期・予算・比率と比べ、説明のつかない増減を探す   | 損益全体                     |
| 質問・閲覧   | 担当者への質問、議事録・稟議書を読む               | 全体（新しい取引・訴訟など） |

## 特にリスクが高いとされるところ

- **収益認識**: 監査では、収益認識に不正のリスクがあると推定して手続を組みます。期末日前後の売上の期ズレ（カットオフ）、返品・値引き、新しい契約の形が見られます。
- **経営者による内部統制の無効化**: どの会社にもあるリスクとして扱われます。そのため、期末の仕訳（特に手入力・通常と違う仕訳）を抽出して確かめる **仕訳テスト** が必ず行われます。
- **会計上の見積り**: 貸倒引当金・棚卸資産の評価減・固定資産の減損・繰延税金資産の回収可能性・退職給付など。前提（将来の計画・割引率など）が合理的か、過去の見積りと実績の差（遡及的な検討）も見られます。

## 経理が意識したいこと

監査人の観点は、経理が自分の決算を確かめる観点と同じです。「この残高は実在する？漏れは無い？金額は正しい？この期の分？」を自分で先に確かめ、その証拠を残しておくことが、一番の監査対策です。
