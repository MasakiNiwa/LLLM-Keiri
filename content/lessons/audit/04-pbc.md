## PBC リストとは

監査人が会社に依頼する資料の一覧です（Prepared by Client = 会社が作る資料）。前年のリストをもとに、監査人と **資料・担当者・提出期限** を合意して管理します。

## 勘定ごとの典型的な資料

| 項目           | 主な資料                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 全体           | 試算表（前期比較）、勘定明細、決算の仕訳の一覧、組織図、取締役会・経営会議の議事録、稟議書、重要な契約書                   |
| 現金預金       | 残高証明書、銀行勘定調整表、現金の実査表                                                                                   |
| 売掛金・売上   | 取引先別の残高明細、**年齢表**（発生からの経過期間）、期末日前後の売上の明細（カットオフ）、返品・値引きの明細、主な契約書 |
| 棚卸資産       | 棚卸の計画と結果、評価減（滞留・陳腐化）の計算、原価計算の資料                                                             |
| 固定資産       | 増減明細、減価償却の計算、取得・売却の証憑、**減損の兆候の検討資料**                                                       |
| 投資・有価証券 | 保有一覧、時価・実質価額の資料、評価損の検討                                                                               |
| 買掛金・未払金 | 取引先別の残高明細、期末日後の支払いの一覧（計上漏れの確かめ）                                                             |
| 借入金         | 残高証明書、契約書（財務制限条項の有無）、返済予定表                                                                       |
| 引当金         | 賞与・退職給付・貸倒など、計算の資料と前提                                                                                 |
| 税金           | 法人税等の計算（別表の下書き）、税効果の計算、**繰延税金資産の回収可能性の検討**（将来の課税所得の見込み）                 |
| 純資産         | 株主資本等変動計算書、増資・配当・自己株式の資料                                                                           |
| 開示           | 注記の資料、セグメント情報、関連当事者との取引の一覧                                                                       |

## 期末前後に準備するもの

- **残高確認**: 監査人が取引先・銀行に確認状を送ります。会社は送付先の一覧を作り、回答の差異の調整（「先方は入金済み、当社は未消込」など）を説明します。確認状は監査人が直接送り、直接回収するのがルールです。
- **弁護士への確認**: 訴訟・係争があれば、顧問弁護士へ状況を問い合わせます。
- **後発事象**: 期末日後、監査報告書の日までに起きた重要な出来事（災害・大きな契約・訴訟の判決など）を一覧にします。
- **経営者確認書**: 経営者が「財務諸表を作る責任を果たした」「すべての資料を提供した」などを監査人に書面で確認するもので、監査報告書の日付で提出します。

## 渡し方のコツ

1. **明細の合計が試算表と一致** していることを確かめてから渡す（一致しない資料は差し戻されます）
2. 増減の大きい科目には、**理由を一言** 添える
3. 前期と様式をそろえ、ファイル名に勘定名と基準日を入れる
4. 個人情報（給与・マイナンバー）は必要な範囲に絞り、受け渡しの方法を決めておく
5. 間に合わない資料は、期限の前に連絡して新しい期限を合意する

## よくある指摘

- 明細と試算表の不一致、前期からの繰越の誤り
- 期末日前後の売上・費用の期ズレ
- 見積りの根拠（計画・前提）が文書になっていない
- 新しい取引の会計処理を、期末になってから相談した
