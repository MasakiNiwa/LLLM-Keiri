## この会社の数字

A 社は、資本金 1,000 万円の中小法人（3 月決算）です。2026 年 3 月期の決算から、申告書を作ります。

| 項目                                               | 金額                   |
| -------------------------------------------------- | ---------------------- |
| 当期純利益（損益計算書）                           | 6,000,000              |
| 当期に支払った配当（前期の決算の配当）             | 1,000,000              |
| 損金経理をした法人税（中間納付）                   | 400,000                |
| 損金経理をした住民税（中間納付）                   | 50,000                 |
| 損金経理をした納税充当金（未払法人税等の繰入）     | 1,750,000              |
| 期首の納税充当金 ／ 当期の取り崩し（前期分の納付） | 1,200,000 ／ 1,200,000 |
| 　うち事業税（損金になる税）                       | 250,000                |
| 交際費等の支出額 ／ うち接待飲食費                 | 9,000,000 ／ 4,000,000 |
| 減価償却の償却超過額                               | 300,000                |
| 受取配当等の益金不算入額                           | 100,000                |

> 学習用に、地方法人税・住民税・事業税の計算、税額控除、欠損金は省いています。

## 手順 1: 別表十五（交際費）

中小法人は「年 800 万円までの定額控除」と「接待飲食費の 50%（200 万円）」の有利なほうを選べます。定額控除の 800 万円が有利なので、**損金不算入額は 9,000,000 − 8,000,000 ＝ 1,000,000 円** です。別表四で加算・社外流出にします。

## 手順 2: 別表四（所得の金額）

| 区分                               | 総額          | 留保          | 社外流出          |
| ---------------------------------- | ------------- | ------------- | ----------------- |
| 当期利益                           | 6,000,000     | 5,000,000     | 1,000,000（配当） |
| 加算: 損金経理をした法人税         | 400,000       | 400,000       |                   |
| 加算: 損金経理をした住民税         | 50,000        | 50,000        |                   |
| 加算: 損金経理をした納税充当金     | 1,750,000     | 1,750,000     |                   |
| 加算: 交際費等の損金不算入額       | 1,000,000     |               | 1,000,000         |
| 加算: 減価償却の償却超過額         | 300,000       | 300,000       |                   |
| 減算: 納税充当金から支出した事業税 | 250,000       | 250,000       |                   |
| 減算: 受取配当等の益金不算入額     | 100,000       |               | 100,000（※）      |
| **所得金額**                       | **9,150,000** | **7,250,000** | **1,900,000**     |

- 法人税・住民税は損金にならないので加算します。会社の中に残る（未払・充当金）ので留保です。
- 前期分の事業税は、払った期に損金になります。決算では納税充当金を取り崩して払っているので、減算します。
- 受取配当等の益金不算入は、会社の外に出たわけではありませんが、別表五(一) に引き継がないので社外流出（※）の欄に書きます。

## 手順 3: 別表一（法人税額）

課税標準は 1,000 円未満を切り捨てた 9,150,000 円です。中小法人は、年 800 万円以下の部分に軽減税率（特例で 15%）がかかります。

- 8,000,000 × 15% ＝ 1,200,000
- 1,150,000 × 23.2% ＝ 266,800
- **法人税額 1,466,800 円**、中間申告で納めた 400,000 円を引いて、**差引の納付額 1,066,800 円**（100 円未満切り捨て）

## 手順 4: 別表五(一)（利益積立金額）

別表四の「留保」は、別表五(一) に引き継がれ、翌期以降の申告につながります。

| 区分           | 期首      | 減        | 増        | 期末      |
| -------------- | --------- | --------- | --------- | --------- |
| 減価償却超過額 | 0         | 0         | 300,000   | 300,000   |
| 納税充当金     | 1,200,000 | 1,200,000 | 1,750,000 | 1,750,000 |

減価償却超過額 300,000 円は、税務上の帳簿価額が会計より 300,000 円大きいことを表します。翌期以降、償却不足になったときや売却したときに認容（減算）され、減っていきます。

## 試してみる

数字を変えると、別表十五から別表五(一)まで、プログラムがその場で計算し直します。「中小法人」のチェックを外すと、交際費は接待飲食費の 50% だけ、税率は 23.2% になります。

```widget
type: tax-return
```

## 経理のポイント

- 申告書は **別表四 → 別表一** の順に、決算の数字から機械的に作れるようにしておくと、税理士との確認が早くなります。
- 交際費の明細（別表十五）、減価償却の明細（別表十六）など、加算・減算の根拠になる明細を決算のときに作っておきます。
- 別表五(一) の期末の残高は、翌期の申告の出発点です。前期の申告書と必ずつながっているかを確かめます。
