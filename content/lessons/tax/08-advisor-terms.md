## 法人税の言葉

| 言葉                   | 意味                                                                         | 経理が用意すること               |
| ---------------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 益金・損金             | 税法での収益・費用。会計の収益・費用とずれることがある                       | ずれの原因になる取引の一覧       |
| 加算・減算（申告調整） | 会計の利益から所得を出すための、別表四での調整                               | 調整項目ごとの金額と根拠         |
| 留保・社外流出         | 加算・減算のうち、翌期以降に戻るもの（留保）と戻らないもの（流出）           | 前期の別表五(一)との引き継ぎ     |
| 損金経理               | 決算（損益計算書）で費用として処理すること。減価償却費などは損金経理が条件   | 決算で計上したかの確認           |
| 決算調整・申告調整     | 決算で処理しないと認められないもの（決算調整）と、申告書だけで調整できるもの | 決算前に、どちらかの確認         |
| 否認                   | 税務調査などで、会社の処理が税法上認められないとされること                   | 根拠資料（契約書・稟議・議事録） |
| 期ズレ                 | 収益・費用の計上時期が、税法上の正しい期とずれていること                     | 期末日前後の取引の明細           |
| 繰越欠損金             | 過去の赤字（欠損金）を将来の所得から差し引ける制度                           | 発生した期と残高の管理           |
| 予定申告・中間申告     | 期の途中で、前期の税額の半分（予定申告）か仮決算で納める                     | 納付額と期限の管理               |
| 修正申告               | 申告した税額が少なかったときに、正しい税額に直す申告                         | 誤りの内容と再計算               |
| 更正の請求             | 申告した税額が多すぎたときに、税務署に減額を求める手続（原則 5 年以内）      | 誤りの内容と根拠                 |

## 消費税の言葉

| 言葉                           | 意味                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| 課税・非課税・免税・不課税     | 取引の区分。非課税は土地の譲渡・利息など、免税は輸出、不課税は給与・寄附・配当など |
| 仕入税額控除                   | 売上の消費税から、仕入・経費の消費税を差し引くこと（インボイスなどの保存が条件）   |
| 課税売上割合                   | 売上全体のうち課税売上の割合。仕入税額控除の計算に使う                             |
| 全額控除（95% ルール）         | 課税売上高 5 億円以下かつ課税売上割合 95% 以上なら、仕入の消費税を全額控除できる   |
| 個別対応方式・一括比例配分方式 | 全額控除できないときの計算方法。仕入を用途ごとに分けるか、まとめて割合を掛けるか   |
| 簡易課税・みなし仕入率         | 売上の消費税に業種ごとの割合を掛けて控除額にする方法                               |
| 控除対象外消費税               | 仕入税額控除できなかった消費税。税抜経理では費用や資産の取得価額などに処理する     |

## 会話のコツ

- 税理士は「事実」を知りたがります。**いつ・誰と・何を・いくらで・どんな契約で** を先に伝えます。
- 「これは経費になりますか？」より、「この支出は〇〇の目的で、参加者は〇〇、金額は〇〇です。交際費と会議費のどちらと考えますか？」と聞くと、答えが早く正確になります。
- 言葉の意味があいまいなときは、その場で確かめます。「損金経理が必要という意味ですか？」
