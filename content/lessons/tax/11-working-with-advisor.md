## 税理士の役割と経理の役割

税理士は、税務の代理・申告書の作成・税務相談を行う専門家です。ただし、**取引の事実を知っているのは会社** です。経理の役割は、税理士が正しく判断できるように、事実と資料を、早く・漏れなく伝えることです。

## 早めに伝えたいこと

| 出来事                           | 税務で関係すること                             |
| -------------------------------- | ---------------------------------------------- |
| 役員の就任・退任・報酬の変更     | 役員給与・役員退職給与の損金算入               |
| 大きな設備の購入・売却・除却     | 減価償却・特別償却や税額控除・固定資産税       |
| 新しい事業・新しい取引の形       | 収益の計上時期・消費税の課税区分               |
| 海外との取引・海外子会社         | 源泉徴収・移転価格・消費税の免税               |
| 取引先の倒産・回収不能           | 貸倒損失・貸倒引当金                           |
| 寄附・資金援助・グループ内の取引 | 寄附金・グループ法人税制                       |
| 組織再編・増資・減資             | 資本金の額による税率や制度の違い・外形標準課税 |
| 賃上げ・設備投資の計画           | 税額控除（賃上げ促進税制など）の要件           |

## 決算前の打ち合わせ（決算の 1〜2 か月前）

1. **着地見込み**: 利益の見込みと、そこからの所得・税額の見込み（**納税予測**）
2. **論点の確認**: 当期の特別な取引の処理、申告調整の項目
3. **決算で決めること**: 損金経理が必要なもの（減価償却・評価損など）、引当金、未払の計上
4. **使える制度**: 税額控除・特別償却などの要件と必要な資料
5. **スケジュール**: 資料の提出日、申告書の確認日、納付日

## 節税と租税回避の境目

税法が認める制度（税額控除・特別償却・少額資産の特例など）を、要件を満たして使うのは正当な節税です。一方、**事業の実態が無い取引** や、**税負担を減らすことだけが目的の不自然な取引** は、否認されたり、重い加算税の対象になったりします。「利益が出たから、期末に必要の無いものを買う」も、お金が出ていく点を考えると、資金繰りの面で得とは限りません。

## 税務調査

税務署などが申告内容を確かめるもので、多くは事前に連絡があり、税理士が立ち会います。

- **準備**: 過去の申告書・決算書・総勘定元帳・証憑・契約書・議事録を、すぐに出せるようにしておく
- **当日**: 聞かれたことに、事実に基づいて答える。分からないことは、確認してから回答する
- **指摘を受けたら**: 内容と根拠を確かめ、納得できる場合は **修正申告** をする

## 修正申告と加算税・延滞税

| 種類           | 主な場面                                                       |
| -------------- | -------------------------------------------------------------- |
| 過少申告加算税 | 申告した税額が少なかった（原則 10%、一定額を超える部分は 15%） |
| 無申告加算税   | 期限までに申告しなかった                                       |
| 重加算税       | 事実を隠したり、偽ったりした（35% または 40%）                 |
| 延滞税         | 納付が遅れた日数に応じてかかる利息のようなもの                 |

税務調査の連絡の前に自分で誤りに気づいて修正申告をすると、加算税がかからない・軽くなる場合があります。誤りに気づいたら、すぐに税理士に相談します。加算税・延滞税は法人税の計算上、損金になりません。
