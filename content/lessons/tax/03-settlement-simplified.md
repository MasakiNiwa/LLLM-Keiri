## 一般課税（原則）の精算

税抜経理では、1 年間に預かった消費税は **仮受消費税等**、払った消費税は **仮払消費税等** にたまっています。
決算で両方を取り崩し、差額を **未払消費税等**（負債）にします。翌期に申告して納めます。

```shiwake
# 決算で、仮受消費税等 150,000 円と仮払消費税等 105,000 円を精算した
仮受消費税等 150,000 / 仮払消費税等 105,000
/ 未払消費税等 45,000
```

仮払のほうが多ければ、差額は還付される（戻ってくる）ので **未収入金** などにします。

> [!NOTE]
> 前の年の納税額が一定以上の事業者は、期の途中で **中間申告** をして消費税を前払いします。中間納付した額は、決算の精算で差し引きます。

## 簡易課税制度

基準期間（法人はふつう前々事業年度）の課税売上高が **5,000 万円以下** の事業者は、事前に届け出ると **簡易課税制度** を選べます。
実際に払った消費税ではなく、預かった消費税に業種ごとの **みなし仕入率** をかけて、控除する額を計算します。

| 区分    | 主な業種           | みなし仕入率 |
| ------- | ------------------ | ------------ |
| 第 1 種 | 卸売業             | 90%          |
| 第 2 種 | 小売業など         | 80%          |
| 第 3 種 | 製造業・建設業など | 70%          |
| 第 4 種 | 飲食店業など       | 60%          |
| 第 5 種 | サービス業など     | 50%          |
| 第 6 種 | 不動産業           | 40%          |

> [!POINT]
> 簡易課税では、控除額は「預かった消費税 × みなし仕入率」で決まるので、仕入のインボイスがなくても計算できます。
> 届出は、原則として適用したい課税期間が始まる前までに出し、2 年間は続けて適用します。

簡易課税の納付額は、実際の仮受と仮払の差と一致しません。決算の精算で、その差を **雑益**（または雑損）にします。

> [!WARNING]
> 事業の区分の判定、2 種類以上の事業がある場合の計算、2 割特例などには細かい決まりがあります。実務では国税庁の最新の案内で確かめてください。

```quiz
type: shiwake
question: 決算で、仮受消費税等 80,000 円と仮払消費税等 50,000 円を精算した（一般課税）。
answer: |
  仮受消費税等 80,000 / 仮払消費税等 50,000
  / 未払消費税等 30,000
explanation: 差額 30,000 円が納める消費税で、申告・納付まで未払消費税等（負債）にします。
```

```quiz
type: choice
question: 簡易課税で、小売業（第 2 種）の事業者が預かった消費税が 100,000 円のとき、納める消費税は？
choices:
  - 20,000 円
  - 80,000 円
  - 実際に払った消費税によって変わる
answer: 0
explanation: 控除額は 100,000 × 80% ＝ 80,000 円。納める額は 100,000 − 80,000 ＝ 20,000 円です。
```
