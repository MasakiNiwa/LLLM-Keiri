## 法人税の申告書のしくみ

法人税の申告書は、たくさんの **別表** でできています。全部を書くわけではなく、会社に関係するものだけを使います。

| 別表           | 内容                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| 別表一         | 申告書の表紙。所得金額から法人税額、中間納付額、差し引き納める税額まで |
| **別表四**     | 所得の金額の計算（当期利益 ＋ 加算 − 減算）                            |
| **別表五(一)** | 利益積立金額・資本金等の額（税務上の純資産）                           |
| 別表五(二)     | 租税公課の納付状況（法人税・住民税・事業税などの期首・期中・期末）     |
| 別表七(一)     | 欠損金の繰越控除                                                       |
| 別表十一       | 引当金（貸倒引当金など）                                               |
| 別表十五       | 交際費等の損金不算入額                                                 |
| 別表十六       | 減価償却資産の償却額の計算                                             |

## 別表四: 所得の金額の計算

当期利益から始め、加算・減算をして所得金額を出します。各行は **総額** を **留保** と **社外流出** に分けます。

- **留保**: 会社の中に残るもの（税務上の純資産を増やす）。例: 納税充当金、減価償却超過額
- **社外流出**: 会社の外に出たもの。例: 配当、交際費の損金不算入額、役員賞与など


> [!POINT]
> 「納税充当金」は、決算で計上した未払法人税等のことです。会計では費用（法人税等）ですが損金にならないので、別表四で **加算・留保** します。

## 別表五(一): 利益積立金額

会計の利益剰余金に、別表四で **留保** した調整の累計を加えた、税務上の利益の蓄積です。
「減価償却超過額」「納税充当金」などが、翌期以降に解消されるまで残ります。会計と税務の純資産の違いの一覧表、と考えるとわかりやすくなります。

```text
期首の利益積立金額 ＋ 当期の留保（別表四の留保の合計） − 当期の配当など ＝ 期末の利益積立金額
```

> [!TIP]
> 税効果会計の「一時差異」は、別表五(一)の留保の項目とほぼ対応します（[税効果会計のきほん](#/learn/tax-tax-effect)）。

```quiz
type: choice
question: 別表四で、交際費等の損金不算入額はどちらに分類される？
choices:
  - 留保
  - 社外流出
answer: 1
explanation: 交際費は会社の外に支出したもので、将来に解消する差異ではないので社外流出です。
```

```quiz
type: choice
question: 減価償却の償却超過額（会計の償却費が税法の限度額を超えた分）は？
choices:
  - 加算・留保
  - 加算・社外流出
  - 減算・留保
answer: 0
explanation: 損金にならないので加算し、資産の帳簿価額の違いとして会社の中に残る（翌期以降に認容される）ので留保です。
```
