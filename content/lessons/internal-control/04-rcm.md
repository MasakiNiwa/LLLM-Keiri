## 財務報告が正しいための 6 つの要件（アサーション）

| 要件                 | 意味                                     | 例: 売上・売掛金                         |
| -------------------- | ---------------------------------------- | ---------------------------------------- |
| **実在性**           | 資産・負債・取引が実際に存在する         | 架空の売上が計上されていない             |
| **網羅性**           | 記録すべきものが漏れなく記録されている   | 出荷した分がすべて売上になっている       |
| **権利と義務の帰属** | 資産は会社の権利、負債は会社の義務である | 預かり品を自社の在庫にしていない         |
| **評価の妥当性**     | 適切な金額で計上されている               | 回収できない売掛金に引当金を設定している |
| **期間配分の適切性** | 正しい期間に計上されている               | 4 月出荷分を 3 月の売上にしていない      |
| **表示の妥当性**     | 正しく分類・表示・開示されている         | 長期の債権を流動資産にしていない         |

## RCM の例（販売プロセス）

| リスク                                 | コントロール                                                 | 要件         | 種類           |
| -------------------------------------- | ------------------------------------------------------------ | ------------ | -------------- |
| 受注のない架空の売上が計上される       | 出荷は、承認済みの受注データがないとシステムで登録できない   | 実在性       | 予防的・自動化 |
| 出荷したのに売上が計上されない         | 月末に、出荷記録と売上計上を経理担当者が照合し、差異を調べる | 網羅性       | 発見的・手作業 |
| 期末をまたぐ出荷が、違う期の売上になる | 決算で、期末前後の出荷と売上計上日を照合する（カットオフ）   | 期間配分     | 発見的・手作業 |
| 回収できない売掛金が過大に残る         | 経理課長が、年齢調べ表をもとに貸倒引当金の計算をレビューする | 評価の妥当性 | 発見的・手作業 |

## コントロールの種類

- **予防的統制** — 誤りや不正を事前に防ぐ（承認・入力チェック・アクセス制限）
- **発見的統制** — 起きた誤りを事後に見つける（照合・レビュー・残高確認）
- **手作業の統制** と **自動化された統制**（システムの機能）

> [!POINT]
> リスクごとに、それを十分に下げる中心のコントロールを **キーコントロール** と呼び、重点的に評価します。予防的と発見的を組み合わせると、リスクを効果的に下げられます。

```quiz
type: choice
question: 「4 月に出荷した商品が、3 月の売上に計上されてしまう」リスクに対応するのは、どの要件？
choices:
  - 実在性
  - 網羅性
  - 期間配分の適切性
answer: 2
explanation: 正しい期間に計上されているかは、期間配分の適切性です。期末前後の出荷と計上日の照合（カットオフ）で確かめます。
```

```quiz
type: choice
question: 「月末に、銀行の残高証明書と帳簿の預金残高を照合する」コントロールの種類は？
choices:
  - 予防的統制
  - 発見的統制
  - 統制環境
answer: 1
explanation: 起きてしまった誤りを事後に見つける照合は、発見的統制です。
```
