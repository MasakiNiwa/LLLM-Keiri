## 4 つの目的

| 目的                         | 内容                                               |
| ---------------------------- | -------------------------------------------------- |
| 業務の有効性及び効率性       | 事業活動の目的を達成するため、業務をうまく進める   |
| 報告の信頼性                 | 財務報告など、組織の内外への報告の信頼性を確保する |
| 事業活動に関わる法令等の遵守 | 法令やルールを守る                                 |
| 資産の保全                   | 資産の取得・使用・処分を、正しい手続きと承認で行う |

J-SOX で評価するのは、このうち **報告の信頼性**（のうち財務報告）にかかわる内部統制です。

## 6 つの基本的要素

| 要素                   | 内容と例                                                                     |
| ---------------------- | ---------------------------------------------------------------------------- |
| **統制環境**           | 組織の気風。経営者の誠実性・倫理観、取締役会や監査役の監視、組織構造、人事   |
| **リスクの評価と対応** | 目的の達成を妨げるリスクを見つけ、分析し、対応を決める                       |
| **統制活動**           | 経営者の命令・指示を実行するための方針と手続き（承認・照合・職務の分離など） |
| **情報と伝達**         | 必要な情報を正しく把握し、組織の内外に正しく伝える                           |
| **モニタリング**       | 内部統制が有効に動いているかを、継続的に・独立して評価する（内部監査など）   |
| **IT への対応**        | IT の環境を踏まえ、IT を使った統制と、IT そのものの統制を行う                |

> [!POINT]
> **統制環境** は、ほかのすべての要素の土台です。経営者がルールを軽んじていれば、どんなに細かい手続きがあっても内部統制は機能しません。

> [!NOTE]
> 内部統制には限界もあります。判断の誤り、不注意、複数の担当者の共謀、想定外の取引、そして **経営者による内部統制の無効化** などです。

```quiz
type: choice
question: 「経理部長の承認がないと支払いができない」というルールは、6 つの基本的要素のどれにあたる？
choices:
  - 統制環境
  - 統制活動
  - モニタリング
answer: 1
explanation: 承認・照合・職務の分離など、具体的な方針と手続きは統制活動です。
```

```quiz
type: choice
question: 内部監査部門が、各部署の手続きが守られているかを定期的に確かめるのは？
choices:
  - リスクの評価と対応
  - 情報と伝達
  - モニタリング
answer: 2
explanation: 内部統制が有効に動いているかを独立した立場で評価するのは、モニタリング（独立的評価）です。
```
