## 経理部門の主なコントロール

| コントロール           | 例                                                                             | 守る要件の例     |
| ---------------------- | ------------------------------------------------------------------------------ | ---------------- |
| **職務の分離**         | 支払いの起票と承認、入金の記帳と現金の管理を別の人が行う                       | 実在性           |
| **仕訳の承認**         | 手入力の仕訳（特に決算整理・修正仕訳）を、起票者と別の人が証憑と照らして承認   | 実在性・評価     |
| **勘定残高の照合**     | 預金は残高証明書、売掛金・買掛金は補助元帳や取引先の残高と照合し、差異を調べる | 実在性・網羅性   |
| **決算チェックリスト** | 決算の手順を一覧にし、実施者・確認者がサインする                               | 網羅性・期間配分 |
| **見積りのレビュー**   | 引当金・減損・税効果などの見積りの前提と計算を、上長がレビューする             | 評価の妥当性     |
| **分析的レビュー**     | 前年・予算と比べて大きく増減した科目の理由を確かめる                           | すべて           |
| **開示のチェック**     | 有価証券報告書などの数字が、財務諸表と一致するかを照合する                     | 表示の妥当性     |

> [!POINT]
> 「誰が・いつ・何を確かめたか」の **証跡** を残すことまでが、経理のコントロールです。

```quiz
type: choice
question: 経理担当者が自分で起票した決算整理仕訳を、自分で承認できる設定になっていた。何が欠けている？
choices:
  - 職務の分離
  - 分析的レビュー
  - 開示のチェック
answer: 0
explanation: 起票と承認を同じ人が行えると、誤りや不正を防げません。起票者と承認者を分ける（職務の分離）ことが必要です。
```
