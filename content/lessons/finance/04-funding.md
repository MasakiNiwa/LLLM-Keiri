## 主な資金調達

| 方法                           | 特徴                                                                       |
| ------------------------------ | -------------------------------------------------------------------------- |
| **証書貸付**                   | 借用証書（金銭消費貸借契約）で借りる。設備資金・長期の運転資金。分割で返済 |
| **手形貸付**                   | 銀行あての手形で借りる。短期の運転資金                                     |
| **当座貸越**                   | 限度額まで、必要なときに借りて返せる                                       |
| **信用保証協会の保証付き融資** | 中小企業が保証を受けて借りやすくする。保証料がかかる                       |
| **手形・電子記録債権の割引**   | 期日前に銀行に買い取ってもらう（割引料がかかる）                           |
| **ファクタリング**             | 売掛金を専門の会社に売って、早くお金にする（手数料がかかる）               |
| **リース**                     | 設備を買わずに借りる。初期の支出を抑える                                   |
| **増資**                       | 株式を発行して資本を集める。返済はいらないが、株主が増える                 |
| **補助金・助成金**             | 返済はいらないが、ふつう事業を行った **あと** に入金される                 |

> [!POINT]
> 補助金・助成金は後払いが多いので、入金されるまでの資金を別に用意する必要があります。資金繰り表に入金の時期を正しく入れます。

## 仕訳

```shiwake
# 銀行から 5 年返済の証書貸付で 3,000,000 円を借り入れ、普通預金に入金された
普通預金 3,000,000 / 借入金 3,000,000

# 毎月の返済（元金 50,000 円・利息 5,000 円）が引き落とされた
借入金 50,000 / 普通預金 55,000
支払利息 5,000 /
```

> [!NOTE]
> 貸借対照表では、決算日の翌日から 1 年以内に返済する分を流動負債（短期借入金・1 年内返済予定の長期借入金）、それ以外を固定負債（長期借入金）に分けて表示します（このアプリの勘定科目は、学習用に「借入金」1 つにしています）。

## 銀行とのつきあい

- 決算書・試算表・**資金繰り表** を定期的に出し、業績と見通しを説明する
- 必要になってからではなく、**余裕のあるうち** に借入れを相談する
- 借入金の残高・返済予定・金利・担保・保証の一覧を作っておく
