## 資金繰り表の形

| 区分           | 主な項目                                           |
| -------------- | -------------------------------------------------- |
| **前月繰越**   | 月初の現金預金の残高                               |
| **経常収入**   | 現金売上、売掛金の回収、受取手形の期日入金         |
| **経常支出**   | 仕入代金・外注費の支払い、人件費、家賃、経費、利息 |
| 経常収支       | 経常収入 − 経常支出（本業でお金が増えたか）        |
| **経常外収支** | 設備の購入・売却、税金の納付、敷金など             |
| **財務収支**   | 借入れ、返済、増資、配当                           |
| **翌月繰越**   | 前月繰越 ＋ 各収支                                 |

> [!POINT]
> 損益計算書の数字を、**いつ入金・出金されるか** に置き換えるのが資金繰り表です。売上は回収の条件（例: 末締め翌々月末入金）、仕入は支払いの条件で、入出金の月がずれます。

## 作り方

1. 売上・仕入・経費の **予定（予算）** を月ごとに出す
2. 取引の **条件（締め日・入金日・支払日）** から、入金・出金の月に振り分ける
3. 税金（中間・確定申告、消費税）、賞与、設備投資、借入れの返済など、**決まった月の大きな支出** を入れる
4. 翌月繰越が、最低限持っておきたい残高を下回る月がないか確かめる
5. 毎月、**実績** を入れて予定と比べ、先の予定を直す

> [!TIP]
> 回収を早める（現金売上の割合を上げる、回収の月を短くする）、支払いを延ばす、借入れを入れるなど、数字を変えて残高がどう変わるか試してみましょう。
