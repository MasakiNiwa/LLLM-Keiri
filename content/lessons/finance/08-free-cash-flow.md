## 3 つの区分

| 区分                             | 主な中身                                                                     | ふつうの会社では |
| -------------------------------- | ---------------------------------------------------------------------------- | ---------------- |
| 営業活動によるキャッシュ・フロー | 本業での入金・支払い（売上の回収、仕入・人件費の支払い、法人税の支払いなど） | プラス           |
| 投資活動によるキャッシュ・フロー | 設備の購入・売却、有価証券の取得・売却、貸付け                               | マイナス         |
| 財務活動によるキャッシュ・フロー | 借入れと返済、増資、配当の支払い                                             | 会社の方針次第   |

## 間接法の営業キャッシュ・フロー

税引前当期純利益から始めて、お金が動かない損益と、運転資金の増減を調整します。

| 調整                     | 向き                           |
| ------------------------ | ------------------------------ |
| 減価償却費・減損損失     | 足す（費用だがお金は出ない）   |
| 売上債権・棚卸資産の増加 | 引く（お金が寝た）             |
| 仕入債務の増加           | 足す（支払いを待ってもらった） |
| 固定資産の売却益         | 引く（入金は投資の区分に入る） |
| 法人税等の支払額         | 引く                           |

利益が出ているのに営業キャッシュ・フローが少ないときは、売掛金や在庫が増えていないかを最初に確かめます（資金繰りのレッスンの「黒字倒産」と同じ構造です）。

## フリー・キャッシュ・フロー

**フリー・キャッシュ・フロー（FCF）＝ 営業キャッシュ・フロー ＋ 投資キャッシュ・フロー**（簡便な計算）

本業で稼いだお金から、事業を続けるための投資を払った後に、自由に使えるお金です。返済・配当・新しい投資の原資になります。設備投資だけを引く計算など、定義は会社や目的によって違います。

例: 営業 CF 120、投資 CF △80 → FCF 40。借入れの返済 30、配当 10 なら、手元のお金はほぼ横ばいです。

## EBITDA

**EBITDA ＝ 営業利益 ＋ 減価償却費**（簡便な計算）。設備の重さ（減価償却の方法・年数）や金利・税金の違いを除いて、本業の稼ぐ力を比べるときに使います。借入金の返済能力を見る「有利子負債 ÷ EBITDA」（何年分の稼ぎで返せるか）もよく使われます。運転資金や設備投資を考えていないので、お金そのものではない点に注意します。

## 組み合わせで読む

| 営業 | 投資 | 財務 | よくある姿                                   |
| ---- | ---- | ---- | -------------------------------------------- |
| ＋   | −    | −    | 本業で稼ぎ、投資し、返済・配当もしている     |
| ＋   | −    | ＋   | 本業で稼ぎ、さらに借入れて大きく投資している |
| −    | ＋   | ＋   | 本業でお金が出ていき、資産売却と借入れで補う |
| −    | −    | ＋   | 立ち上げ期など、借入れ・増資で投資している   |

一つの期だけで決めつけず、数期の流れで見ます。
