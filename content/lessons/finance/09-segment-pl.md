## 段階的に見る損益

| 段階           | 計算                                      | 何がわかるか                     |
| -------------- | ----------------------------------------- | -------------------------------- |
| 限界利益       | 売上高 − 変動費                           | 1 個売るごとに増える利益         |
| 貢献利益       | 限界利益 − その部門だけの固定費           | その部門が会社の利益に貢献した額 |
| 部門の営業利益 | 貢献利益 − 配賦された共通費（本社費など） | 全社の費用まで負担した後の利益   |

## 赤字の部門をやめるべき？

例: B 部門の損益

| 項目               | 金額 |
| ------------------ | ---- |
| 売上高             | 100  |
| 変動費             | 60   |
| 限界利益           | 40   |
| B 部門だけの固定費 | 25   |
| 貢献利益           | 15   |
| 配賦された本社費   | 20   |
| 部門の営業利益     | △5   |

部門の営業利益は赤字ですが、貢献利益は 15 のプラスです。B 部門をやめても本社費 20 は残るので、会社全体の利益は **15 減ります**。判断には、配賦後の利益ではなく **やめたら本当に無くなる収益と費用（関連する収益・原価）** を使います。

## 配賦の注意

- 本社費・共通費の配賦基準（売上高・人数・面積・作業時間など）は、費用が発生する原因に近いものを選び、毎期同じ基準を使います。
- 基準を変えると、どの部門の利益も変わります。報告では基準を明記します。
- 部門長の評価には、その部門が **自分で管理できる** 費用まで（貢献利益など）を使うと納得感が出ます。

## 損益分岐点との関係

限界利益率（限界利益 ÷ 売上高）を使うと、部門ごとの損益分岐点売上高（固定費 ÷ 限界利益率）も計算できます。原価計算のトラックの CVP 分析と組み合わせて使います。

## セグメント情報との違い

上場会社が開示するセグメント情報は、経営者が意思決定に使う区分（マネジメント・アプローチ）で開示します。社内の部門別損益の作り方が、そのまま開示の土台になります。財務諸表の読み方のトラックの「連結財務諸表とセグメント情報を読む」も参考にしてください。
