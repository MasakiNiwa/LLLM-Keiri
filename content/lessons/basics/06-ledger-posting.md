## 仕訳帳と総勘定元帳

仕訳は日付順に **仕訳帳** に記録します。でも仕訳帳だけでは、「いま現金がいくらあるか」がすぐにはわかりません。
そこで、仕訳を勘定科目ごとの帳簿 **総勘定元帳**（そうかんじょうもとちょう）に書き写します。これを **転記** といいます。

勘定科目ごとのページを **勘定** と呼び、学習では左右に分けた **T 字勘定** で表します。

## 転記のしかた

仕訳の **借方の科目は、その勘定の借方に**、**貸方の科目は、その勘定の貸方に** 書きます。
金額と一緒に、日付と **相手の勘定科目** を書くのがルールです。

```shiwake
# 4/1 株主から 500,000 円の出資を受け、現金で受け取った
現金 500,000 / 資本金 500,000

# 4/5 商品 80,000 円を仕入れ、現金で支払った
仕入 80,000 / 現金 80,000

# 4/10 商品を 120,000 円で売り、現金で受け取った
現金 120,000 / 売上 120,000
```

これを現金勘定に転記すると、次のようになります。

| 借方       |    金額 | 貸方     |   金額 |
| ---------- | ------: | -------- | -----: |
| 4/1 資本金 | 500,000 | 4/5 仕入 | 80,000 |
| 4/10 売上  | 120,000 |          |        |

## 残高の求め方

勘定の **残高** は、借方合計と貸方合計の差です。

- 借方合計 620,000 − 貸方合計 80,000 ＝ **540,000**（借方残高）

資産の勘定は、ふつう **借方残高**、負債・純資産の勘定は **貸方残高** になります。
収益は貸方残高、費用は借方残高です。

> [!POINT]
> 勘定の残高は、5 つの要素の「増える側」に残るのがふつうです。
> 現金勘定が貸方残高（マイナス）になったら、どこかで記録を間違えています。

> [!TIP]
> 「帳簿」ページでは、自分で入れた仕訳がその場で T 字勘定に転記され、残高まで計算されます。

```quiz
type: choice
question: 「仕入 80,000 / 買掛金 80,000」を転記するとき、買掛金勘定にはどう書く？
choices:
  - 借方に「仕入 80,000」
  - 貸方に「仕入 80,000」
  - 貸方に「買掛金 80,000」
answer: 1
explanation: 買掛金は仕訳の貸方なので、買掛金勘定の貸方に、相手の科目「仕入」と金額を書きます。
```
