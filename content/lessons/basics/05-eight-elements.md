## 取引の 8 要素

5 つの要素の増減を、借方に来るもの・貸方に来るものに分けると 8 つになります。

| 借方（左）に来るもの | 貸方（右）に来るもの |
| -------------------- | -------------------- |
| 資産の増加           | 資産の減少           |
| 負債の減少           | 負債の増加           |
| 純資産の減少         | 純資産の増加         |
| 費用の発生           | 収益の発生           |

どの取引も、**左の列から 1 つ以上・右の列から 1 つ以上** の組み合わせになります。

## よくある組み合わせ

```shiwake
# 資産の増加 ⇔ 資産の減少: 現金を普通預金に預けた
普通預金 50,000 / 現金 50,000

# 資産の増加 ⇔ 負債の増加: 銀行から借り入れた
普通預金 500,000 / 借入金 500,000

# 資産の増加 ⇔ 純資産の増加: 株主から出資を受けた
普通預金 3,000,000 / 資本金 3,000,000

# 資産の増加 ⇔ 収益の発生: サービスの手数料を現金で受け取った
現金 20,000 / 受取手数料 20,000

# 負債の減少 ⇔ 資産の減少: 買掛金を支払った
買掛金 40,000 / 普通預金 40,000

# 費用の発生 ⇔ 資産の減少: 電気代を支払った
水道光熱費 12,000 / 普通預金 12,000

# 費用の発生 ⇔ 負債の増加: 広告の代金を月末払いにした（商品以外の後払いは未払金）
広告宣伝費 30,000 / 未払金 30,000
```

## 簿記上の取引とは

簿記で記録するのは、**資産・負債・純資産・収益・費用が増減するできごと** だけです。
ふだんの言葉の「取引」とは、少しずれがあります。

| できごと                               | ふだんの言葉 | 簿記上の取引                       |
| -------------------------------------- | ------------ | ---------------------------------- |
| 商品の注文を受けた（まだ渡していない） | 取引         | **ではない**（何も増減していない） |
| 事務所の賃貸借契約を結んだ             | 取引         | **ではない**（契約だけ）           |
| 火事で倉庫の商品が焼けた               | 取引ではない | **取引**（資産が減った）           |
| 現金を盗まれた                         | 取引ではない | **取引**（資産が減った）           |

> [!POINT]
> 「お金やモノ、権利・義務の金額が変わったか」で判断します。契約・注文・約束だけでは記録しません。
> ただし、手付金（内金）を払ったり受け取ったりすれば、その分は取引です。

```quiz
type: choice
question: 簿記上の取引にあたるものはどれ？
choices:
  - 商品 100,000 円の注文を受けた
  - 店舗の賃貸借契約を結んだ
  - 現金 5,000 円を紛失した
answer: 2
explanation: 現金（資産）が減っているので簿記上の取引です。注文や契約だけでは、資産・負債などは増減しません。
```
