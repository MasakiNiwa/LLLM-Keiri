## 試算表とは

**試算表**（しさんひょう、Trial Balance）は、総勘定元帳のすべての勘定の金額を 1 つの表にまとめたものです。
仕訳は必ず貸借が一致しているので、正しく転記できていれば、**試算表の借方合計と貸方合計も一致** します。

試算表には 3 つの形があります。

| 種類           | 載せる金額                 |
| -------------- | -------------------------- |
| 合計試算表     | 各勘定の借方合計・貸方合計 |
| 残高試算表     | 各勘定の残高               |
| 合計残高試算表 | 合計と残高の両方           |

## 残高試算表の例

前のレッスンの 3 つの取引（出資・仕入・売上）の残高試算表です。

|    借方残高 | 勘定科目 |    貸方残高 |
| ----------: | -------- | ----------: |
|     540,000 | 現金     |             |
|             | 資本金   |     500,000 |
|             | 売上     |     120,000 |
|      80,000 | 仕入     |             |
| **620,000** | 合計     | **620,000** |

並べ方は、資産 → 負債 → 純資産 → 収益 → 費用 の順がふつうです。

## 試算表で見つけられない誤り

試算表の貸借が一致しても、すべてが正しいとは限りません。

- 仕訳そのものをしていない（取引の記録もれ）
- 借方と貸方の両方に同じ誤った金額を書いた
- 勘定科目を間違えた（例: 売掛金を未収入金にした）
- 同じ仕訳を 2 回転記した

> [!POINT]
> 試算表は「貸借の転記ミス」は見つけられますが、「仕訳の判断ミス」は見つけられません。

## 試算表から決算書へ

残高試算表の上半分（資産・負債・純資産）が **貸借対照表**、下半分（収益・費用）が **損益計算書** のもとになります。
上の例では、収益 120,000 − 費用 80,000 ＝ 当期純利益 40,000 円です。

> [!NOTE]
> 実際の決算では、試算表のあとに **決算整理**（売れ残った商品の調整・減価償却など）を行ってから決算書を作ります。
> 「決算」の分野でくわしく学びます。

```quiz
type: choice
question: 試算表の貸借が一致していても見つけられない誤りは？
choices:
  - 借方だけに転記して、貸方への転記を忘れた
  - 取引の仕訳そのものを忘れた
  - 借方に 10,000、貸方に 1,000 と転記した
answer: 1
explanation: 仕訳もれは借方・貸方の両方が抜けるので、合計は一致したままです。片方だけの転記もれや金額の違いは、貸借の不一致で気づけます。
```
