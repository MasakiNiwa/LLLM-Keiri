## 勘定科目と 5 つのグループ

取引を記録するときに使う「現金」「売上」「買掛金」などの名前を **勘定科目** といいます。
勘定科目は、次の 5 つのグループ（要素）のどれかに入ります。

| 要素       | 意味                                 | 勘定科目の例                       |
| ---------- | ------------------------------------ | ---------------------------------- |
| **資産**   | 会社が持っている財産・権利           | 現金、普通預金、売掛金、建物、備品 |
| **負債**   | 将来支払う義務（借金など）           | 買掛金、借入金、未払金、預り金     |
| **純資産** | 資産から負債を引いた、会社自身の元手 | 資本金、繰越利益剰余金             |
| **収益**   | もうけの原因（純資産を増やす）       | 売上、受取利息、受取手数料         |
| **費用**   | もうけを減らす原因（純資産を減らす） | 仕入、給料、支払家賃、水道光熱費   |

> [!POINT]
> 資産・負債・純資産は「ある時点で、何をどれだけ持っているか」（ストック）、
> 収益・費用は「ある期間に、どれだけ増えたか・使ったか」（フロー）を表します。

## 見分けるコツ

- **資産**: 「持っているとうれしいもの」。お金そのもの、お金を受け取る権利（売掛金・貸付金）、使えるモノ（建物・備品）
- **負債**: 「あとで払わなければいけないもの」。お金を支払う義務（買掛金・借入金・未払金）、商品を渡す義務（前受金）
- **純資産**: 「株主が出したお金」と「これまでのもうけの蓄え」
- **収益**: 「受取〇〇」「売上」など、入ってくる理由
- **費用**: 「支払〇〇」「〇〇費」など、出ていく理由

> [!WARNING]
> 「売掛金」（資産）と「買掛金」（負債）、「未収入金」（資産）と「未払金」（負債）は、名前が似ていて間違えやすい組み合わせです。
> **受け取る権利は資産、支払う義務は負債** と覚えましょう。

## 増えたら左？右？

5 つの要素は、**増えたときに記入する側** が決まっています。

| 要素   | 増えたら   | 減ったら                 |
| ------ | ---------- | ------------------------ |
| 資産   | 借方（左） | 貸方（右）               |
| 負債   | 貸方（右） | 借方（左）               |
| 純資産 | 貸方（右） | 借方（左）               |
| 収益   | 貸方（右） | （ふつうは発生するだけ） |
| 費用   | 借方（左） | （ふつうは発生するだけ） |

資産と費用は **左** で増え、負債・純資産・収益は **右** で増えます。
この表が、仕訳を考えるときのいちばんの基本です。

```shiwake
# 銀行から 1,000,000 円を借り、普通預金に入金された（資産の増加・負債の増加）
普通預金 1,000,000 / 借入金 1,000,000

# 家賃 100,000 円を普通預金から支払った（費用の発生・資産の減少）
支払家賃 100,000 / 普通預金 100,000
```

```quiz
type: choice
question: 「買掛金」はどの要素？
choices:
  - 資産
  - 負債
  - 収益
  - 費用
answer: 1
explanation: 買掛金は、掛けで仕入れた代金を支払う義務なので負債です。受け取る権利の「売掛金」は資産です。
```

```quiz
type: choice
question: 費用が発生したとき、記入するのはどちら側？
choices:
  - 借方（左）
  - 貸方（右）
answer: 0
explanation: 費用は資産と同じく、借方（左）で増えます。
```
