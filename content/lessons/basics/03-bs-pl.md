## 貸借対照表（B/S）

**貸借対照表**（たいしゃくたいしょうひょう、Balance Sheet）は、決算日など **ある時点** の財政状態を表します。

| 借方（左）         | 貸方（右）         |
| ------------------ | ------------------ |
| **資産** 1,500,000 | **負債** 600,000   |
|                    | **純資産** 900,000 |
| 合計 1,500,000     | 合計 1,500,000     |

左に資産、右に負債と純資産を並べます。左右の合計は必ず一致します。

> [!POINT]
> **資産 ＝ 負債 ＋ 純資産**（貸借対照表等式）。
> 右側は「お金をどこから集めたか（他人から＝負債、自分から＝純資産）」、
> 左側は「集めたお金を何に使っているか」と読むこともできます。

## 損益計算書（P/L）

**損益計算書**（Profit and Loss Statement）は、1 年間などの **一定期間** の経営成績を表します。

| 借方（左）             | 貸方（右）         |
| ---------------------- | ------------------ |
| **費用** 2,400,000     | **収益** 2,700,000 |
| **当期純利益** 300,000 |                    |
| 合計 2,700,000         | 合計 2,700,000     |

収益から費用を引いた残りが **当期純利益** です（費用のほうが多ければ当期純損失）。

> [!POINT]
> **収益 − 費用 ＝ 当期純利益**

## 2 つの表のつながり

当期純利益は、決算で純資産（繰越利益剰余金）に加わります。
つまり、もうけた分だけ会社の元手が増えます。

- 期首の純資産 600,000 ＋ 当期純利益 300,000 ＝ 期末の純資産 900,000

このように、損益計算書は「純資産がなぜ増えたか（減ったか）」の理由を説明する表でもあります。

> [!NOTE]
> 実際の決算書（会社法の計算書類や金融商品取引法の財務諸表）では、勘定式（左右に並べる形）のほかに、
> 上から下へ並べる **報告式** もよく使われます。損益計算書は、売上総利益・営業利益・経常利益…と段階的に利益を示します。

```quiz
type: choice
question: 「ある時点の財政状態」を表すのはどちら？
choices:
  - 貸借対照表
  - 損益計算書
answer: 0
explanation: 貸借対照表は決算日などある時点の資産・負債・純資産、損益計算書は一定期間の収益・費用と利益を表します。
```

```quiz
type: choice
question: 資産 1,200,000 円、負債 500,000 円のとき、純資産はいくら？
choices:
  - 500,000 円
  - 700,000 円
  - 1,700,000 円
answer: 1
explanation: 資産 ＝ 負債 ＋ 純資産 なので、純資産 ＝ 1,200,000 − 500,000 ＝ 700,000 円です。
```
