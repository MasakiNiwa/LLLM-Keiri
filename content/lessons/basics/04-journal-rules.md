## 仕訳とは

**仕訳**（しわけ）は、取引を「どの勘定科目が、いくら、増えたか減ったか」に分解して、借方（左）と貸方（右）に書き分けることです。

```shiwake
# 備品 300,000 円を買い、代金は普通預金から支払った
備品 300,000 / 普通預金 300,000
```

このサイトでは、仕訳を「借方科目 金額 / 貸方科目 金額」の形で表示します。

## 仕訳の 3 つの手順

1. **何が動いたか** を探す（勘定科目を決める）
2. それぞれが **増えたか・減ったか** を考える
3. 5 つの要素の表に当てはめて、**左右** を決める

| 要素         | 増えたら | 減ったら |
| ------------ | -------- | -------- |
| 資産         | 借方     | 貸方     |
| 負債・純資産 | 貸方     | 借方     |
| 収益（発生） | 貸方     | —        |
| 費用（発生） | 借方     | —        |

### 例: 商品を掛けで仕入れた

「商品 80,000 円を仕入れ、代金は掛けとした」

1. 動いたもの: 商品の仕入（**仕入**）と、後で払う義務（**買掛金**）
2. 仕入（費用）が発生、買掛金（負債）が増えた
3. 費用の発生は借方、負債の増加は貸方

```shiwake
# 商品 80,000 円を掛けで仕入れた
仕入 80,000 / 買掛金 80,000
```

### 例: 掛け代金を支払った

「上の買掛金 80,000 円を、普通預金から支払った」

1. 動いたもの: **買掛金** と **普通預金**
2. 買掛金（負債）が減った、普通預金（資産）が減った
3. 負債の減少は借方、資産の減少は貸方

```shiwake
# 買掛金 80,000 円を普通預金から支払った
買掛金 80,000 / 普通預金 80,000
```

## 貸借一致の原則

どんな仕訳でも、**借方の合計と貸方の合計は必ず等しく** なります。
1 つの取引に勘定科目が 3 つ以上出てくることもあります（**複合仕訳**）。

```shiwake
# 借入金 100,000 円と利息 2,000 円を、普通預金から返済した
借入金 100,000 / 普通預金 102,000
支払利息 2,000 /
```

借方は 100,000 ＋ 2,000 ＝ 102,000、貸方は 102,000 で一致しています。

> [!TIP]
> 迷ったら、まず **お金（現金・預金）がどちらに動いたか** から決めると楽です。
> お金が入れば借方、出ていけば貸方。もう片方には、その理由（相手の科目）が入ります。

```quiz
type: choice
question: 「給料 250,000 円を普通預金から支払った」の仕訳として正しいものは？
choices:
  - 給料 250,000 / 普通預金 250,000
  - 普通預金 250,000 / 給料 250,000
  - 給料 250,000 / 未払金 250,000
answer: 0
explanation: 給料（費用）の発生は借方、普通預金（資産）の減少は貸方です。
```
