## 約束手形

**約束手形** は、決まった日（満期日）に代金を払うことを約束する証券です。

| 立場                 | 科目                 |
| -------------------- | -------------------- |
| 受け取った側（債権） | **受取手形**（資産） |
| 振り出した側（債務） | **支払手形**（負債） |

```shiwake
# 商品 200,000 円を売り、代金として約束手形を受け取った
受取手形 200,000 / 売上 200,000

# 満期日に、手形の代金が普通預金に入金された
普通預金 200,000 / 受取手形 200,000
```

## 満期前に使う

### 割引（銀行に買い取ってもらう）

満期前に銀行へ手形を渡して、お金に換えることを **手形の割引** といいます。満期までの利息にあたる **割引料** が差し引かれ、**手形売却損** になります。

```shiwake
# 受取手形 200,000 円を銀行で割り引き、割引料 4,000 円を差し引かれて普通預金に入金された
普通預金 196,000 / 受取手形 200,000
手形売却損 4,000 /
```

### 裏書（ほかの支払いに使う）

手形の裏に署名して、仕入先などへの支払いに使うことを **裏書（裏書譲渡）** といいます。

```shiwake
# 買掛金 150,000 円の支払いに、持っていた約束手形を裏書して渡した
買掛金 150,000 / 受取手形 150,000
```

## 電子記録債権（でんさい）

**電子記録債権** は、電子債権記録機関に記録することで発生する債権です。紙の手形と同じように使え、印紙税がかからない、なくす心配がないなどの利点があります。

```shiwake
# 売掛金 300,000 円について、得意先の請求により電子記録債権の発生記録が行われた
電子記録債権 300,000 / 売掛金 300,000

# 買掛金 120,000 円について、仕入先への電子記録債務の発生記録を行った
買掛金 120,000 / 電子記録債務 120,000
```

> [!NOTE]
> 国や金融業界は、紙の約束手形の利用をやめ、電子記録債権などへ移る方針を示しています。実務では電子記録債権の取扱いが増えています。

```quiz
type: shiwake
question: 受取手形 500,000 円を銀行で割り引き、割引料 6,000 円を差し引かれた額が当座預金に入金された。
answer: |
  当座預金 494,000 / 受取手形 500,000
  手形売却損 6,000 /
explanation: 手形の額面をすべて減らし、差し引かれた割引料は手形売却損（営業外費用）にします。
```

```quiz
type: choice
question: 仕入先への買掛金の支払いのために、持っていた約束手形を裏書して渡した。減る資産は？
choices:
  - 支払手形
  - 受取手形
  - 普通預金
answer: 1
explanation: 持っていた手形（受取手形）を渡したので、受取手形が減ります。
```
