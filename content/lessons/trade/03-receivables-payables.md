## 債権と債務

- **債権**: お金などを受け取る権利（資産）
- **債務**: お金などを支払う義務（負債）

似た名前の科目がたくさんありますが、2 つの観点で整理できます。

|                      | 本業の商品・サービス | それ以外（備品・車両・土地など） |
| -------------------- | -------------------- | -------------------------------- |
| 後で受け取る（債権） | **売掛金**           | **未収入金**                     |
| 後で支払う（債務）   | **買掛金**           | **未払金**                       |

```shiwake
# 商品を掛けで売った（本業）
売掛金 50,000 / 売上 50,000

# 使わなくなった備品を帳簿価額と同じ 30,000 円で売り、代金は月末に受け取る（本業以外）
未収入金 30,000 / 備品 30,000

# 事務所用のパソコン 200,000 円を買い、代金は翌月払い（本業以外）
備品 200,000 / 未払金 200,000
```

## 前払金と前受金

商品の受け渡しより先に代金の一部（内金・手付金）をやりとりしたときに使います。

```shiwake
# 商品を注文し、内金 20,000 円を現金で支払った
前払金 20,000 / 現金 20,000

# 商品 100,000 円を受け取り、内金を差し引いた残りは掛けとした
仕入 100,000 / 前払金 20,000
/ 買掛金 80,000
```

受け取った側は **前受金**（商品を渡す義務＝負債）にします。

```shiwake
# 注文を受け、内金 20,000 円を現金で受け取った
現金 20,000 / 前受金 20,000

# 商品 100,000 円を渡し、内金を差し引いた残りは掛けとした
前受金 20,000 / 売上 100,000
売掛金 80,000 /
```

## 仮払金と仮受金

内容や金額が **まだ確定していない** 支払い・入金を一時的に記録する科目です。確定したら正しい科目に振り替えます。

```shiwake
# 出張する社員に、旅費の概算 30,000 円を現金で渡した
仮払金 30,000 / 現金 30,000

# 帰社後に精算: 旅費は 26,000 円で、残りを現金で受け取った
旅費交通費 26,000 / 仮払金 30,000
現金 4,000 /

# 内容不明の入金 70,000 円があった
普通預金 70,000 / 仮受金 70,000

# 売掛金の回収だとわかった
仮受金 70,000 / 売掛金 70,000
```

> [!TIP]
> 実務では、仮払金・仮受金が残ったままになっていないかを毎月チェックします。決算書に大きく残るのは好ましくありません。

```quiz
type: choice
question: 営業用の車を買い、代金は来月払うことにした。貸方の科目は？
choices:
  - 買掛金
  - 未払金
  - 前受金
answer: 1
explanation: 商品以外（車両）の代金を後で支払う義務は「未払金」です。買掛金は本業の商品の仕入代金に使います。
```
