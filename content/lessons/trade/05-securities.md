## 持つ目的で分ける

| 分類                     | 例                             | 期末の評価                 |
| ------------------------ | ------------------------------ | -------------------------- |
| 売買目的有価証券         | 値上がりで利益を得るための株式 | **時価**（差額は損益）     |
| 満期保有目的債券         | 満期まで持つ社債・国債         | 取得原価（または償却原価） |
| 子会社株式・関連会社株式 | 支配・影響のための株式         | 取得原価                   |
| その他有価証券           | 持ち合い株式など               | **時価**（差額は純資産）   |

## 売買目的有価証券

### 取得

買入手数料などの付随費用は、**取得原価に含めます**。

```shiwake
# A 社株式 1,000 株を 1 株 500 円で買い、手数料 5,000 円とあわせて普通預金から支払った
売買目的有価証券 505,000 / 普通預金 505,000
```

### 売却

帳簿価額（1 株あたり 505 円）との差額を、**有価証券売却益** または **有価証券売却損** にします。

```shiwake
# A 社株式 400 株を 1 株 560 円で売り、代金は普通預金に入金された（帳簿価額 505 円 × 400 株 ＝ 202,000 円）
普通預金 224,000 / 売買目的有価証券 202,000
/ 有価証券売却益 22,000
```

> [!NOTE]
> 同じ銘柄を何回かに分けて違う単価で買ったときは、平均した単価（移動平均法など）で帳簿価額を出します。

### 期末の評価（時価に評価替え）

```shiwake
# 決算で、残っている A 社株式 600 株（帳簿価額 303,000 円）の時価は 1 株 480 円（288,000 円）だった
有価証券評価損 15,000 / 売買目的有価証券 15,000
```

## その他有価証券

時価に評価替えしますが、差額は損益にせず、純資産の **その他有価証券評価差額金** にします（全部純資産直入法）。翌期首には元の帳簿価額に戻します（洗替法）。

```shiwake
# 決算で、取得原価 800,000 円の B 社株式（その他有価証券）の時価が 900,000 円だった（税効果は考えない）
その他有価証券 100,000 / その他有価証券評価差額金 100,000
```

> [!WARNING]
> 実務では、その他有価証券の評価差額には税効果会計を適用します。また、時価が著しく下がって回復の見込みがないときは、減損処理として損失にします。

```quiz
type: shiwake
question: 売買目的で C 社株式 200 株を 1 株 1,200 円で買い、手数料 3,000 円とあわせて普通預金から支払った。
answer: 売買目的有価証券 243,000 / 普通預金 243,000
explanation: 手数料も取得原価に含めるので、240,000 ＋ 3,000 ＝ 243,000 円です。
```

```quiz
type: choice
question: 売買目的有価証券の期末の時価が帳簿価額より低い。差額はどうする？
choices:
  - 有価証券評価損（損益）にする
  - その他有価証券評価差額金（純資産）にする
  - 何もしない
answer: 0
explanation: 売買目的有価証券は時価に評価替えし、差額は損益（有価証券評価損）にします。
```
