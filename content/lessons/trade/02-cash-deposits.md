## 簿記の「現金」

簿記では、紙幣・硬貨に加えて、すぐにお金にかえられる **通貨代用証券** も **現金** として扱います。

- 他人が振り出した小切手（他人振出小切手）
- 送金小切手、郵便為替証書
- 支払期日の来た公社債の利札 など

```shiwake
# 売掛金 40,000 円の回収として、取引先振出の小切手を受け取った
現金 40,000 / 売掛金 40,000
```

> [!WARNING]
> **自分で振り出した小切手** で支払ったときは、当座預金が減ります（現金ではありません）。

```shiwake
# 買掛金 70,000 円を、小切手を振り出して支払った
買掛金 70,000 / 当座預金 70,000
```

## 預金の種類

| 勘定科目 | 特徴                                               |
| -------- | -------------------------------------------------- |
| 普通預金 | いつでも出し入れできる。振込・引き落としに使う     |
| 当座預金 | 小切手・手形の支払いに使う。利息はつかない         |
| 定期預金 | 期間を決めて預ける。原則として満期まで引き出せない |

実務では、銀行や口座ごとに「普通預金（A 銀行）」のように補助科目で分けて管理します。

```shiwake
# 普通預金から定期預金に 300,000 円を預け替えた
定期預金 300,000 / 普通預金 300,000
```

## 現金過不足

金庫の現金を数えたら、帳簿の残高と合わないことがあります。原因がわかるまで、**現金過不足** で一時的に記録し、帳簿を実際の額に合わせます。

```shiwake
# 帳簿残高 50,000 円、実際は 48,000 円（2,000 円不足）
現金過不足 2,000 / 現金 2,000

# 原因を調べたら、交通費 1,500 円の記帳もれだった
旅費交通費 1,500 / 現金過不足 1,500

# 決算日まで残り 500 円の原因がわからなかった
雑損 500 / 現金過不足 500
```

> [!POINT]
> 不足（実際が少ない）なら借方に現金過不足、過剰（実際が多い）なら貸方に現金過不足。
> 決算までに原因がわからなければ、不足は **雑損**、過剰は **雑益** にします。
