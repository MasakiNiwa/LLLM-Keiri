## 三分法

商品の売買は、**仕入**（費用）・**売上**（収益）・**繰越商品**（資産）の 3 つの勘定で記録するのが一般的です。これを **三分法** といいます。

- 仕入れたとき: 原価で **仕入** に記録
- 売ったとき: 売価で **売上** に記録
- 期末に残った商品: 決算で **繰越商品** に振り替える

```shiwake
# 商品 60,000 円を仕入れ、代金は掛けとした
仕入 60,000 / 買掛金 60,000

# その商品を 90,000 円で売り、代金は掛けとした
売掛金 90,000 / 売上 90,000
```

> [!POINT]
> 売ったときに「商品が減った」とは記録しません。売上は **売価** で記録し、もうけ（売上総利益）は決算で売上原価を計算して求めます。

## 仕入の付随費用

商品を仕入れるときにかかった **引取運賃**・運送保険料などは、**仕入の原価に含めます**。

```shiwake
# 商品 50,000 円を掛けで仕入れ、引取運賃 2,000 円を現金で支払った
仕入 52,000 / 買掛金 50,000
/ 現金 2,000
```

一方、商品を売るときにこちらが負担する送料は **発送費**（費用）にします。

```shiwake
# 商品 30,000 円を掛けで売り、送料 1,000 円を現金で支払った（当社負担）
売掛金 30,000 / 売上 30,000
発送費 1,000 / 現金 1,000
```

> [!NOTE]
> 送料を買い手から受け取る約束（売り手が立て替えて請求する）なら、送料分も売上に含めて売掛金で請求する方法が一般的です（収益認識基準の考え方）。

## 返品

返品は、元の仕訳の **逆仕訳** で取り消します。

```shiwake
# 掛けで仕入れた商品のうち 5,000 円分を返品した（仕入戻し）
買掛金 5,000 / 仕入 5,000

# 掛けで売った商品のうち 8,000 円分が返品された（売上戻り）
売上 8,000 / 売掛金 8,000
```

## 売上原価と売上総利益（さわり）

もうけは、売上から **売れた商品の原価（売上原価）** を引いて求めます。

- 売上原価 ＝ 期首の在庫 ＋ 当期の仕入 − 期末の在庫
- 売上総利益（粗利）＝ 売上 − 売上原価

この計算は決算整理で行います（「決算」の分野でくわしく）。

