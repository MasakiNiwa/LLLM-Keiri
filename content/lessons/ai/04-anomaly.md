## サンプルから全件へ

人の目で見るときは、一部を抜き出して確かめる（サンプリング）しかありませんでした。データで分析すれば、**すべての仕訳** を同じ基準で確かめられます。会計監査や内部監査でも、仕訳の全件をデータで分析する手法が広く使われています。

## よく見るパターン

| 観点             | 例                                                     |
| ---------------- | ------------------------------------------------------ |
| 時間             | 休日・深夜の入力、決算日の直前・直後の大きな仕訳       |
| 人               | ふだん仕訳を入れない人の入力、入力と承認が同じ人       |
| 金額             | ちょうどの金額（端数が無い）、承認の上限のすぐ下の金額 |
| 科目の組み合わせ | 売上と現金以外の科目、めったに使わない科目の組み合わせ |
| 摘要             | 摘要が空欄、「調整」「修正」だけ                       |
| 取引先           | 新しい取引先への多額の支払い、口座の変更直後の支払い   |

**ベンフォードの法則**: 自然に発生した金額の先頭の数字は、1 が約 30%、9 が約 5% と、小さい数字ほど多くなる傾向があります。分布が大きく外れていると、作られた数字が混ざっている可能性を疑うきっかけになります（それだけで不正とは言えません）。

## 3 つのやり方

1. **ルール**: 上の表の条件を決めて抽出する。説明しやすい。
2. **統計**: 前年・前月・同じ取引先との比較で、外れた値を見つける。
3. **機械学習**: たくさんの特徴の組み合わせから「いつもと違う」を点数にする。新しいパターンにも気づけるが、なぜ選ばれたかの説明が難しいことがある。

## 人が判断すること

検知されたものの多くは、理由のある取引です（決算の修正・まとめての支払いなど）。大切なのは、

- 抽出された仕訳を **誰が・いつ・どう確かめたか** の記録を残す
- 本当の問題が見つかったら、**なぜ統制で防げなかったか** まで考える（J-SOX の不備の評価へ）
- 抽出の条件を、見つかったことを反映して見直す

ことです。異常検知は、不正を「見つける」だけでなく、「見られている」ことで防ぐ効果もあります。
