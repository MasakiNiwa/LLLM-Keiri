## 関連会社と持分法

議決権の **20% 以上** を持つなど、財務や営業の方針に **重要な影響** を与えている会社は **関連会社** です（子会社を除く）。
関連会社は、資産や負債を合算する連結（全部連結）はせず、**持分法** で取り込みます。

> [!POINT]
> 持分法は「一行連結」とも呼ばれます。関連会社の利益のうち自社の持分だけを、**投資（関連会社株式）** の 1 行に反映させます。

## 利益の取り込み

関連会社 A（持分 30%）の当期純利益が 200 なら、自社の持分は 200 × 30% ＝ 60。

```shiwake
# 関連会社の当期純利益のうち持分を取り込む
関連会社株式 60 / 持分法による投資損益 60
```

## 配当を受け取ったとき

関連会社から配当 30 を受け取ると、個別の帳簿では受取配当金にしています。
持分法では、配当は投資の払い戻しと考えるので、受取配当金を消して投資を減らします。

```shiwake
# 関連会社からの配当金 30 の修正
受取配当金 30 / 関連会社株式 30
```

## 連結（全部連結）との違い

|                    | 子会社（連結）                             | 関連会社（持分法）                             |
| ------------------ | ------------------------------------------ | ---------------------------------------------- |
| 判定               | 支配している（過半数など）                 | 重要な影響を与えている（20% 以上など）         |
| 取り込み方         | 資産・負債・収益・費用をすべて合算         | 投資の 1 行と、持分法による投資損益の 1 行だけ |
| 当期純利益への影響 | 親会社株主に帰属する当期純利益は同じになる | 同じ                                           |

> [!NOTE]
> 投資額と関連会社の資本の持分との差額（のれんに相当する部分）は、投資の中に含めたまま償却し、持分法による投資損益に含めます。

```quiz
type: shiwake
question: 関連会社 B（持分 25%）の当期純利益は 400 だった。持分法で取り込む。
answer: 関連会社株式 100 / 持分法による投資損益 100
explanation: 400 × 25% ＝ 100 を、関連会社株式の増加と持分法による投資損益にします。
```
