## セグメント情報とは

連結財務諸表は、グループ全体を 1 つの会社とみなした数字です。いくつもの事業や地域で商売をしているグループでは、
全体の数字だけでは「どの事業がもうかっているか」がわかりません。
そこで、グループを **セグメント**（事業の種類や地域の区分）に分けて、売上高・利益・資産などを示します。これが **セグメント情報** です。

> [!POINT]
> セグメントの分け方は、経営者が意思決定や業績の評価に使っている区分に合わせます（**マネジメント・アプローチ**）。
> そのため、同じ業種でも会社によってセグメントの分け方や利益の測り方が違います。

## 主な項目

| 項目                     | 中身                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| 外部顧客への売上高       | グループの外の顧客への売上高                                     |
| セグメント間の内部売上高 | ほかのセグメントへの売上高（連結では消去される）                 |
| セグメント利益           | 経営者が使う利益（営業利益とすることが多い）                     |
| セグメント資産           | セグメントの資産（経営者に報告している場合）                     |
| 調整額                   | セグメントの合計と連結の金額の差（セグメント間の取引の消去など） |

## 調整額を読む

製造事業の子会社 S 社が、小売事業の P 社（親会社）に製品を 60,000 売り、P 社の期末の商品に S 社の利益 3,000 が残っているとします。

| 売上高         | 小売事業 | 製造事業 | 計      | 調整額  | 連結    |
| -------------- | -------- | -------- | ------- | ------- | ------- |
| 外部顧客への   | 200,000  | 50,000   | 250,000 | —       | 250,000 |
| セグメント間の | —        | 60,000   | 60,000  | △60,000 | —       |
| 計             | 200,000  | 110,000  | 310,000 | △60,000 | 250,000 |

- セグメントの売上高は、セグメント間の売上高を **含めて** 示す
- 連結ではグループ内の売上を消去するので、その分が調整額（△60,000）になる
- セグメント利益の調整額には、未実現利益の消去（△3,000）などが入る

> [!TIP]
> 「連結」ページの「事業の種類別のセグメント情報（製造と小売）」で、セグメントの金額や調整額を押すと、
> どの会社のどの科目か、どの連結修正仕訳から来たかをたどれます（ドリルダウン）。

> [!NOTE]
> 実際の開示では、ほかに減価償却費や地域ごとの情報、主要な顧客の情報なども示します。ここでは基本の項目だけを扱います。

```quiz
type: choice
question: セグメントの分け方は、何にもとづいて決める？
choices:
  - 業種ごとに法令で決められた区分
  - 経営者が意思決定や業績の評価に使っている区分
  - 売上高の大きい順に 3 つ
answer: 1
explanation: セグメント情報はマネジメント・アプローチによるので、経営者が内部で使っている区分に合わせます。
```

```quiz
type: choice
question: 製造事業から小売事業への売上高 60,000 は、セグメント情報ではどう表示される？
choices:
  - どちらのセグメントにも含めない
  - 製造事業の売上高（セグメント間の内部売上高）に含め、調整額で消去する
  - 小売事業の売上高に含める
answer: 1
explanation: セグメント間の売上高は売り手のセグメントの売上高に含めて示し、連結の金額とは調整額で合わせます。
```
