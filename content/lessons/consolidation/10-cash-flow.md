## キャッシュ・フロー計算書とは

損益計算書の利益と、実際に増えたお金（現金及び現金同等物）は一致しません。売上が掛けなら、利益は出てもお金はまだ入っていないからです。
**キャッシュ・フロー計算書** は、1 年間のお金の増減を、次の 3 つに分けて示します。

| 区分         | 主な中身                                                 |
| ------------ | -------------------------------------------------------- |
| **営業活動** | 商品の売買・給料・税金など、本業によるお金の増減         |
| **投資活動** | 固定資産・有価証券の取得と売却、貸付け、子会社株式の取得 |
| **財務活動** | 借入れと返済、株式の発行、配当金の支払い                 |

## 営業活動の 2 つの書き方

- **直接法**: 「営業収入」「仕入の支出」など、お金の出入りをそのまま並べる
- **間接法**: 税金等調整前当期純利益から始めて、お金の動かない費用・収益や、売掛金・在庫などの増減を調整する

```
税金等調整前当期純利益            300
  減価償却費・のれん償却額          +  60   （お金の出ない費用を足し戻す）
  売上債権の増加                    −  80   （売ったのにまだ入金されていない）
  棚卸資産の減少                    +  20
  仕入債務の増加                    +  30   （仕入れたのにまだ払っていない）
営業活動によるキャッシュ・フロー    330
```

> [!POINT]
> 間接法では、利益を出発点にして「お金が動かなかった分」を調整します。実務では間接法がほとんどです。

## 連結ならではの注意点

### 作り方は 2 つ

- **原則法**: 各社のキャッシュ・フロー計算書を合算し、グループ内のお金のやりとり（親子間の売買代金・貸付け・配当）を相殺消去する
- **簡便法**: 連結貸借対照表と連結損益計算書から直接作る（期首と期末の連結貸借対照表の増減から間接法で作る）

### 区分の決まり

| 項目                                     | 区分                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------- |
| 親会社が子会社から受け取った配当金       | 相殺消去（グループ内のやりとり）                                       |
| 子会社が **非支配株主** に支払った配当金 | 財務活動（「非支配株主への配当金の支払額」）                           |
| 新しく子会社になった会社の株式の取得     | 投資活動（取得価額から子会社の持っていた現金を差し引いて、1 行で表示） |
| 在外子会社のお金の換算差額               | 「現金及び現金同等物に係る換算差額」として別に表示                     |
| のれん償却額                             | 営業活動（間接法）でお金の出ない費用として足し戻す                     |

> [!NOTE]
> 在外子会社のキャッシュ・フローは、原則として期中平均レートで換算します。期首と期末の現金の残高は決算日レートで換算するので、その差は「換算差額」として調整します。

> [!TIP]
> 利益とお金の流れのずれを感じるには、「帳簿」ページで売掛金で売った取引と、現金で売った取引を入れて、損益計算書と普通預金の残高を見比べてみましょう。

```quiz
type: choice
question: 連結キャッシュ・フロー計算書で、子会社が非支配株主に支払った配当金はどの区分？
choices:
  - 営業活動
  - 投資活動
  - 財務活動
answer: 2
explanation: 非支配株主への配当金の支払いは、グループの外の株主への資金の返還なので、財務活動のキャッシュ・フローです。親会社への配当は、グループ内のやりとりとして相殺消去します。
```

```quiz
type: choice
question: 間接法の営業活動によるキャッシュ・フローで、売上債権（売掛金）が増えたときはどう調整する？
choices:
  - 増えた分を足す
  - 増えた分を引く
  - 調整しない
answer: 1
explanation: 売上として利益に入っているのに、まだお金が入っていない分なので、利益から差し引きます。
```
