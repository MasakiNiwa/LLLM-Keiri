## 取引の日のレートで記録する

海外の会社とドルで取引したら、**取引が発生した日の為替相場** で円に換算して記録します。

```shiwake
# 商品 1,000 ドルを輸出し、代金は掛けとした（1 ドル 150 円）
売掛金 150,000 / 売上 150,000
```

## 決済したとき

代金を受け取る日にレートが変わっていたら、その差額は **為替差損益** です。

```shiwake
# 上の売掛金 1,000 ドルを回収し、普通預金に入金した（1 ドル 145 円）
普通預金 145,000 / 売掛金 150,000
為替差損 5,000 /
```

円高（1 ドルが 150 円 → 145 円）になったので、受け取る円が減り、損になりました。

## 決算のとき

期末に残っている外貨建ての **金銭債権・債務**（売掛金・買掛金・預金・借入金など）は、**決算日のレート** で換算し直し、差額を為替差損益にします。

```shiwake
# 期末に買掛金 500 ドル（記録したときは 1 ドル 148 円 ＝ 74,000 円）が残っている。決算日は 1 ドル 150 円
為替差損 1,000 / 買掛金 1,000
```

円安で、支払う円が増える（74,000 → 75,000 円）ので、買掛金を増やして損にします。

> [!POINT]
> 換算し直すのは、お金で決済される **金銭債権・債務** です。商品（在庫）・前払金・前受金・固定資産などは、取引の日のレートのままにします。

## 前払金があるとき

前払金（手付金）を払った分は、前払金を払った日のレートのまま仕入に充てます。

```shiwake
# 商品 1,000 ドルを輸入。100 ドルは前払金（払ったときは 1 ドル 150 円）、残り 900 ドルは掛け（1 ドル 145 円）
仕入 145,500 / 前払金 15,000
/ 買掛金 130,500
```

> [!NOTE]
> 為替予約（将来のレートをあらかじめ決める契約）で為替の変動に備えることもあります。
> 為替差損益は、損益計算書では差し引きして「為替差益」または「為替差損」として営業外損益に表示します。

```quiz
type: shiwake
question: 商品 2,000 ドルを輸出し、代金は掛けとした（1 ドル 145 円）。
answer: 売掛金 290,000 / 売上 290,000
explanation: 取引の日のレートで換算します。2,000 × 145 ＝ 290,000 円。
```

```quiz
type: shiwake
question: 上の売掛金 2,000 ドル（290,000 円で記録）が期末に残っている。決算日のレートは 1 ドル 150 円である。
answer: 売掛金 10,000 / 為替差益 10,000
hint: 決算日のレートで換算し直すと、いくらになりますか？
explanation: 2,000 × 150 ＝ 300,000 円。記録より 10,000 円増えるので、売掛金を増やして為替差益にします。
```
